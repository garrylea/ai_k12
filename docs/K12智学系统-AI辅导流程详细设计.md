# K12 智学系统 — AI 辅导与双轨学习流程详细设计

> 对应 PRD 第 6 节“学习场景（双轨制）”与第 7.1 节“AI 辅导引擎（双轨支持）”的展开设计。

## 1. 模块定位

AI 辅导是系统的双轨学习核心：

- **主线**：学生按教材章节自主学习，AI 在课程卡片中作为“随时可唤起的苏格拉底式讨论伙伴”，帮助学生理解知识点。
- **辅线**：学生可脱离课程进度，针对任意知识点或任意题目与 AI 自由探讨。

无论主/辅线，AI 都遵循“不直接给答案、引导孩子自己思考”的原则，并严格限定学习边界，禁止闲聊。

## 2. 双轨架构

```text
┌─────────────────────────────────────────────────────────┐
│                      K12 智学系统                        │
├─────────────────────────┬───────────────────────────────┤
│        主线：自主学习    │         辅线：自由探索         │
├─────────────────────────┼───────────────────────────────┤
│ 1. 教材卡片阅读          │ 1. 任意知识点讲解              │
│ 2. 点击“讨论”与 AI 探讨  │ 2. 任意题目答疑                │
│ 3. 课后真题作业          │ 3. 自主上传错题/难题           │
│ 4. 错题进入主线错题本    │ 4. 错题进入辅线错题本          │
│ 5. 清零解锁下一课/单元   │ 5. 不影响主线进度              │
└─────────────────────────┴───────────────────────────────┘
```

## 3. 主线：自主学习流程

### 3.1 学习内容组织

- 以教材版本（如人教版）为骨架，按“章 → 单元 → 课”组织。
- 每节课由若干张**教材原文卡片**组成，卡片内容直接来自公开教材文字提取。
- 每张卡片底部有一个**“讨论”按钮**，学生可随时发起 AI 讨论。
- 课程最后提供课后作业入口。

### 3.2 主线学习流程

```text
开始
  │
  ▼
清除上一课/上一单元所有错题
  │
  ▼
发放上一课/上一单元奖励
  │
  ▼
判断进入内容
  │
  ├─ 上一课不是单元最后一课 ──> 进入下一课学习
  │
  ├─ 上一课是单元最后一课 ────> 进入单元检测
  │
  ├─ 学期进度到达中间单元 ────> 进入期中考试
  │
  └─ 学期全部单元已学完 ──────> 进入期末考试
  │
  ▼
学习/检测流程
  │
  ├─ 课程学习：阅读卡片 → 点击“讨论” → 完成课后作业
  │
  └─ 各类检测：系统组卷 → 限时作答 → 自动批改
  │
  ▼
错题进入主线错题本
  │
  ▼
错题是否全部清零？
  │
  ├─ 是 ──> 解锁下一课/单元/阶段，发放对应奖励
  │
  └─ 否 ──> 停留在当前进度，逐题重做
```

**流程说明**：

1. **错题清零先行**：学生必须先清除上一课/上一单元的所有主线错题，才能进入新的学习内容或检测。
2. **奖励发放**：错题清零后，系统发放上一课/上一单元的闯关奖励。
3. **内容判断**：
   - 普通情况：进入下一课学习。
   - 单元结束：进入单元检测。
   - 学期中点：进入期中考试。
   - 学期结束：进入期末考试。
4. **检测错题**：单元检测、期中/期末考试中的错题同样进入主线错题本，需清零后方可继续。

### 3.3 主线“讨论”模式

**触发条件**：学生在阅读某张教材卡片时，点击卡片底部的“讨论”按钮。

**讨论范围**：严格限定在当前卡片展示的知识点内容，AI 不能脱离该范围。

**AI 行为**：

1. 读取当前卡片原文作为上下文。
2. 学生可输入“这页我没看懂”“这句话什么意思”“为什么是这样”等。
3. AI 用苏格拉底式提问引导学生逐步理解卡片内容。
4. 讨论不记录为错题，仅作为学习辅助。

**示例**：

```text
【卡片内容】
速度 = 路程 ÷ 时间

学生：这句话我没看懂
AI：好，我们先不急着记公式。你平时走路去学校，走得快和走得慢，有什么区别呢？
学生：快的话花的时间少
AI：对！那如果两家离学校一样远，谁用的时间少，谁就更快？
学生：是的
AI：所以“速度”其实就是在说“快”和“慢”。路程一样时，时间越短，速度就越___？
学生：大
AI：没错！所以速度 = 路程 ÷ 时间，就是告诉我们：用总路程除以所用时间，就能得到快慢。你现在能用自己的话解释这个公式吗？
```

### 3.4 课后作业

- 每个知识点配置 **2-3 道真题**，难度分为 **易、中、难**。
- 真题来源：公开试卷（月考、期中、期末、历年真题），按知识点标签抽取。
- 学生作答时：
  - 可直接提交答案。
  - 不会时可点击“提示”，系统给出下一步思路（非完整答案）。
  - 仍不会时可点击“让 AI 讲一讲”，进入苏格拉底式题目辅导。
- 错题自动进入**主线错题本**。

### 3.5 单元检测与期中/期末考试

- **单元检测**：每单元最后一课的作业错题清零后触发，覆盖本单元所有知识点。
- **期中考试**：学期进度到达中间单元时触发，覆盖前半学期已学单元。
- **期末考试**：学期全部单元学完后触发，覆盖整学期内容。
- 考试流程：
  1. 系统根据考试范围自动组卷。
  2. 学生限时作答。
  3. 系统自动批改并生成成绩报告。
  4. 考试错题进入主线错题本。
  5. 学生需将考试错题全部清零后，方可继续后续学习。

## 4. 辅线：自由探索流程

### 4.1 入口

学生可在非主线上课阶段随时进入辅线：

- 顶部导航“自由探索”。
- 首页“问 AI 一个问题”。
- 拍照/上传任意题目。
- 选择任意知识点进行讲解。

### 4.2 辅线辅导流程

与主线“讨论”类似，但范围不限于当前卡片：

1. 学生提出问题或上传题目。
2. AI 判断问题所属知识点（如已知）。
3. AI 采用苏格拉底式提问引导学生思考。
4. 学生可要求换种方式讲解、出类似题、深入追问。

### 4.3 辅线错题本

- 辅线中的错题进入**辅线错题本**。
- 辅线错题不影响主线课程解锁。
- 学生可自主选择复习辅线错题。

## 5. 错题处理机制

### 5.1 错题来源

| 来源 | 进入哪个错题本 | 是否影响主线解锁 |
|------|----------------|------------------|
| 主线课后作业 | 主线错题本 | 是 |
| 主线单元检测 | 主线错题本 | 是 |
| 主线期中/期末考试 | 主线错题本 | 是 |
| 辅线自由探索 | 辅线错题本 | 否 |
| 主线卡片“讨论” | 不计入错题 | 否 |

### 5.2 错题清零规则

- 错题重做：**做对一次即可清零**。
- 若再次做错：
  - 提升错题级别（如从 Level 1 升至 Level 2）。
  - AI 给出解析时，重新梳理相关知识点。
  - 追加 1-2 道同类变式题，直到做对为止。
- 课程解锁：上一课/单元所有主线错题必须全部清零后，才能进入下一课/单元。

### 5.3 错题复习流程

```text
学生进入错题本
  │
  ▼
选择一道错题重做
  │
  ▼
做对？
  │
  ├─ 是 ──> 标记为已掌握，从待清零列表移除
  │
  └─ 否 ──> 提升错题级别，AI 重新讲解知识点，追加变式题
```

## 6. AI 苏格拉底式辅导策略

### 6.1 通用原则

- 不直接给答案。
- 从学生已知出发，逐步引导。
- 多轮对话，根据回答调整下一步问题。
- 用肯定和鼓励维持学习动力。

### 6.2 主线讨论 vs 辅线辅导

| 维度 | 主线“讨论” | 辅线辅导 |
|------|-------------|----------|
| 触发方式 | 卡片页“讨论”按钮 | 自由提问/拍照/选知识点 |
| 知识范围 | 严格限定当前卡片 | 不限，可跨知识点 |
| 上下文 | 卡片原文 + 学生问题 | 学生问题/题目 + 可选知识点 |
| 是否生成错题 | 否 | 是（若涉及做题） |
| 目标 | 理解教材知识点 | 解决疑问、深入思考 |

### 6.3 讨论/辅导结束条件

- 学生表示“我懂了”“明白了”。
- 学生主动结束讨论。
- 连续多轮无法推进，AI 建议降低难度或查看解析。
- 触发闲聊边界且学生不回归学习主题。

## 7. 边界控制：禁止闲聊

与 PRD 保持一致：所有 AI 交互需先判断是否为学习内容。

- **允许**：与当前卡片/题目/知识点相关的问题。
- **拒绝**：问候、天气、游戏、娱乐、隐私打探、敏感话题等。
- **拒绝话术**：温和引导孩子回到学习主题。

## 8. 输入与交互

### 8.1 主线卡片页

- 左右/上下滑动切换卡片。
- 每张卡片底部固定“讨论”按钮。
- 讨论区以对话气泡形式展开，不遮挡卡片内容。

### 8.2 课后作业页

- 题目展示区 + 作答区。
- “提示”按钮：给出下一步思路。
- “让 AI 讲一讲”按钮：进入苏格拉底式辅导。
- 提交后显示判题结果和解析入口。

### 8.3 辅线探索页

- 顶部输入框：文字/公式提问。
- 拍照按钮：上传题目图片。
- 知识点选择器：按学科-学段-章节浏览知识点。

## 9. 与系统其他模块的关系

| 模块 | 交互 |
|------|------|
| 内容与课程体系 | 提供教材卡片、知识点结构、真题题库 |
| 主线错题本 | 接收主线作业/测试错题，控制课程解锁 |
| 辅线错题本 | 接收辅线探索错题，供自主复习 |
| 闯关与奖励机制 | 主线课程完成且错题清零后发放奖励 |
| 家长端 | 展示学习进度、错题情况、奖励记录 |
| 自动判题 | 判断作业答案正误，支持提示与解析 |

## 10. 关键交互示例（主线课后作业）

**场景**：初一学生做“有理数加法”课后作业。

```text
【题目】计算：(-3) + 5

学生：不会
AI：好，我们先不看负数。如果是 3 + 5，你知道等于多少吗？
学生：8
AI：很好！那 (-3) + 5 可以理解为“欠了 3 元，又得到 5 元”，最后还剩多少？
学生：2
AI：对！所以 (-3) + 5 = 2。你能总结出“异号两数相加”的规律吗？
学生：绝对值相减，取大的符号
AI：非常准确！记住这个规律，你试试下一题。
```

## 11. 待进一步确认的问题

- 教材卡片是否允许 AI 在后期对原文进行改写，还是必须严格保留原教材文字？
- 课后作业的真题来源是否需要人工审核或去重？
- 错题再次做错时，提升级别的具体规则是什么（最多几级？每级对应什么处理）？
- 辅线中是否允许学生直接要求 AI 给出答案？若不允许，如何设计话术？
- 家长端是否需要查看辅线学习记录，还是只关注主线进度？
