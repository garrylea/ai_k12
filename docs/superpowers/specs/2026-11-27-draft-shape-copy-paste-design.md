## 1. 目标

学生在草稿白板的「选中」工具中选中一个或多个笔迹/图形后，可用
`Ctrl/Cmd+C` 复制、`Ctrl/Cmd+V` 粘贴。

- 第一次粘贴相对原图形向右下各偏移 10px。
- 连续粘贴按 10px、20px、30px……递增，避免副本完全重叠。
- 粘贴完成后选中新副本，学生可立即拖动、旋转或删除。
- 复制与粘贴都不能破坏现有图片粘贴、输入框原生快捷键和草稿撤销/重做。

非目标：

- 不把草稿图形写入系统剪贴板，不支持跨应用、跨页面粘贴。
- 不新增贴图复制；只选中贴图时仍走现有系统图片粘贴链路。
- 不提供工具栏复制/粘贴按钮。
- 不改变已落笔图形扁平化为 `Stroke` 的数据模型。

## 2. 方案选型

| 方案 | 结论 | 理由 |
|---|---|---|
| **草稿组件内部快照剪贴板** | 选定 | 不依赖 Clipboard API 权限；不污染系统剪贴板；不与图片文件粘贴争用；图形快照可精确深拷贝 |
| 系统剪贴板自定义 MIME | 否决 | Safari/Electron 的权限、焦点和自定义 MIME 支持不稳定，且更容易与截图粘贴冲突 |
| 页面级全局变量保存剪贴板 | 否决 | 当前需求只在同一草稿内复制粘贴；跨草稿/跨题共享会扩大状态边界，YAGNI |

剪贴板保存在 `DraftWhiteboard` 的 ref 中，内容为复制瞬间的图形深拷贝。
组件卸载或 `questionId` 变化时丢弃，保持各题草稿隔离。

## 3. 数据与状态

```ts
interface StrokeClipboard {
  /** 复制瞬间的深拷贝；后续移动/旋转原图形不得改变这里 */
  strokes: Stroke[];
}

const clipboardRef = useRef<StrokeClipboard | null>(null);
/** 本轮复制后的粘贴序号；第一次粘贴 = 1 */
const pasteGenerationRef = useRef(0);
```

每次复制：

1. 读取 `selectedStrokesRef.current`。
2. 对每条选中笔迹调用现有 `cloneStroke`，点对象与 `center` 都新建。
3. 保存到 `clipboardRef`，并把 `pasteGenerationRef` 重置为 0。

切题时：

1. `clipboardRef.current = null`。
2. `pasteGenerationRef.current = 0`。

## 4. 快捷键与事件流

### 4.1 复制

监听 `document.keydown`：

- 仅在 `tool === 'select'` 时处理。
- 仅接受 `Ctrl/Cmd+C`，带 `Alt` 时忽略。
- 没有选中笔迹时放行。
- 有手势正在进行时忽略，避免复制到半截状态。
- 命中时 `preventDefault()`，深拷贝选区到内部剪贴板。

复制本身不改草稿内容，不写 store，不产生撤销步骤。

### 4.2 粘贴

复用 `DraftWhiteboard` 现有的 `document.paste` 监听：

1. 当前为「选中」工具且存在内部图形剪贴板时，先粘贴图形；这一步优先于焦点位置和系统剪贴板旧内容。
2. 否则输入框/文本域内直接放行。
3. 没有内部图形剪贴板、剪贴板含图片文件时，执行现有 `insertImages`。
4. 存在内部图形剪贴板且当前为「选中」工具时：
   - `preventDefault()`。
   - `pasteGenerationRef += 1`。
   - 深拷贝剪贴板中的每条笔迹，所有点与圆心标记额外偏移
     `10 * pasteGenerationRef` px（x、y 同增）。
   - 追加到 `strokesRef.current`，`persist` 为真时写回 `setDraft`。
   - 整次粘贴只调用一次 `pushHistory()`。
   - 把新副本设为当前选区并重绘。
5. 没有内部图形剪贴板时放行浏览器默认行为。

粘贴过程中若检测到手势正在进行，则不处理，保持按钮/绘图状态一致。

### 4.3 与现有快捷键的关系

| 按键 | 行为 |
|---|---|
| `Ctrl/Cmd+C` | 复制选中笔迹/图形；选中图形时即使焦点在输入框也优先复制草稿；无选区时保留原生行为 |
| `Ctrl/Cmd+V` | 有内部图形时优先粘贴图形；否则输入框/图片粘贴走原生行为 |
| `Ctrl/Cmd+Z` | 撤销；一次粘贴可一次撤销 |
| `Ctrl/Cmd+Shift+Z`、`Ctrl+Y` | 重做 |
| Delete/Backspace | 删除粘贴后自动选中的副本 |

## 5. 交互细节

- 偏移方向固定为右下，x/y 各 10px；不做画板边界夹取，保证“相对上一次粘贴刚好 10px”的确定性。
- 多选复制时，每个图形使用同一个粘贴序号和相同 `(+10, +10)` 位移，保持相对布局。
- 副本完整保留点列、压力、线宽、颜色、虚线、圆心标记。
- 复制后移动或旋转原图，不影响内部剪贴板；再次粘贴仍从复制瞬间的几何位置计算偏移。
- 粘贴只选中新副本，不把原图形留在选区。
- 清空草稿不清空内部剪贴板；清空后仍可粘贴复制过的图形。
- 每次重新复制都会重置偏移序列，下一次粘贴从 10px 开始。
- 撤销粘贴后再次粘贴，序号继续递增；行为与普通连续粘贴一致。

## 6. 实现边界

主要改动位于 `apps/web/src/components/business/DraftWhiteboard.tsx`：

- 新增剪贴板与粘贴序号 ref。
- 扩展现有 `paste` effect，在图片优先级之后处理内部图形剪贴板。
- 新增「选中」工具下的复制键盘 effect。
- 复用 `cloneStroke`、`setDraft`、`pushHistory`、`setSelection`、`redraw`。
- 切题初始化 effect 同时清空复制状态。

不改 `Stroke` / `DraftImage` 类型，不改 `draft-store`、`draft-history`，不改服务端和 API。

## 7. 测试

在 `DraftWhiteboard.test.tsx` 增加组件交互回归：

1. 选中矩形后 `Ctrl+C`、`Ctrl+V`：新增一条图形，所有点和圆心相对原图偏移 `(+10, +10)`。
2. 连续 `Ctrl+V`：第二条副本偏移 `(+20, +20)`，第三条偏移 `(+30, +30)`。
3. 复制后移动原图，再粘贴：副本仍基于复制瞬间的位置偏移 10px。
4. 粘贴一次后 `Ctrl+Z`：只撤销该次粘贴，原图和之前内容保留。
5. 多选两个图形复制粘贴：两条副本整体同量偏移，并成为当前选区。
6. 选中图形后焦点仍在输入框：`Ctrl/Cmd+C` / `Ctrl/Cmd+V` 仍复制粘贴草稿图形。
7. 已复制图形、系统剪贴板仍含旧图片时按 `Ctrl+V`：只粘贴图形，不同时插入旧图片。
8. 只选中贴图时 `Ctrl+C`：不占用图片的原生复制粘贴路径。
9. 切换 `questionId` 后粘贴：不会把上一题图形带入新题。

测试必须先在实现前失败，再写最小实现转绿；完成后执行草稿白板测试、Web 全量测试、构建和 ESLint。

## 9. 验收标准

1. 选中一个矩形后按 `Ctrl/Cmd+C`、`Ctrl/Cmd+V`，出现与原件形状和属性一致的新矩形，位置右下各偏 10px。
2. 连续粘贴形成 10/20/30px 台阶，不会完全重叠。
3. 粘贴后副本处于选中态，可拖动、旋转、Delete 删除。
4. 一次粘贴可一次撤销；复制本身不占撤销步骤。
5. 题目输入框、题干图片粘贴、系统截图粘贴行为不回归。
6. 切题后内部剪贴板清空，不跨题粘贴。
