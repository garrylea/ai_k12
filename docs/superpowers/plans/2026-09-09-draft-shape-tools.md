# 草稿白板图形工具（圆规 / 直线 / 矩形 / 椭圆 / 三角形）——四阶段计划

日期：2026-09-09
关联：`docs/superpowers/plans/2026-09-02-draft-whiteboard-design.md`（白板初始设计）、PRD §7.12（草稿白板）、`apps/web/src/components/business/DraftWhiteboard.tsx`

## 1. 背景与目标

草稿白板目前只有 手写笔 / 橡皮 / 移动 三个工具（贴图、两指平移为后续增量）。学生做几何题需要在草稿里画规整图形（圆弧辅助线、直线、矩形、椭圆、三角形），纯手写难以画准。本期为白板增加 5 个图形工具，按用户指定优先级分四阶段交付：

| 阶段 | 内容 | 优先级 |
|---|---|---|
| Phase 1 | **圆规**（调半径 → 定圆心，画弧与整圆） | 最高，本期完成 |
| Phase 2 | 直线（Shift 锁 0°/45°/90°） | 其次 |
| Phase 3 | 矩形（Shift 正方形）、椭圆（Shift 正圆） | 再次 |
| Phase 4 | 三角形（Shift 等边；**创建期各顶点可拖拽调整**） | 最后 |

## 2. 总体架构决策（四阶段共用）

### 2.1 图形落笔即采样为 Stroke（扁平化，不存形状对象）

所有图形工具在**确认时**采样为 `Stroke { points, size }`（与手写笔同一数据结构），进入既有笔迹管道：

- 渲染：`strokePath()` 二次贝塞尔平滑统一画法，主题色自适应免费获得；
- 擦除：橡皮「笔画级擦除」语义天然延伸为「整条图形一次擦掉」（对学生是期望行为：擦一个圆就是删整个圆）；
- 持久化：`draft-store` 的 `setDraft/getDraft` 原样复用，persist=true/false 两种挂载模式无差别。

**取舍**：落笔后的图形不可再作为「形状」选中编辑（不能事后拖动圆心改半径）。用户需求里唯一明确要「拖拽调整」的是三角形顶点——限定在**创建确认之前**的调整期完成（见 Phase 4），确认后同样扁平化。若远期需要事后编辑，需引入 Shape 数据模型，另立计划。

### 2.2 采样密度

弦长自适应：步长角 `Δθ = 2·asin(min(1.5, r/2) / r)`（相邻采样点弦长约 3px），整圆最少 64 点封底。弧按起止角区间采样、两端点闭合。

### 2.3 交互骨架（拖拽预览 → 确认提交）

所有图形工具共用同一交互骨架，Phase 1 圆规先建立该骨架：

```
选工具 → 指针手势（实时虚线/实线预览，Shift 约束）→ 抬手/按钮确认 → 采样为 Stroke 提交
```

工具栏布局：图形工具按钮与 手写笔/橡皮/移动 同排；工具激活且带有附加操作时（圆规的「整圆/重置」），工具条下方出现**条件渲染的第二行控制条**（提示文案 + 操作按钮），避免主工具条在 40% 窄抽屉下溢出。

### 2.4 状态生命周期约定

- 图形工具的进行中状态存组件 ref（指针手势态）；切换到其他工具**保留**该 ref（学生擦错一笔后切回继续画，符合真实圆规「放下再拿起」的心智），但参考线/预览仅在工具激活时渲染；
- 切题（remount / persist 加载）、清空按钮 → 状态重置回未放置；
- scroll-y 两指平移、pointercancel、lostpointercapture 打断 → 取消进行中的预览（不提交），已确认图形不受影响。

## 3. Phase 1 详细设计：圆规

### 3.1 交互规范（状态机）

`CompassState`（`draft-compass.ts`）：

```ts
type CompassState =
  | { phase: 'idle' }                                                  // 未放置
  | { phase: 'ready'; cx; cy; r }                                      // 圆心+半径已定
  | { phase: 'placing'; cx; cy; r }    // 过渡：按下即定圆心，拖动调半径
  | { phase: 'resizing'; cx; cy; r }   // 过渡：拖住半径手柄调半径
  | { phase: 'drawing'; cx; cy; r; a0; sweep }  // 画弧进行中（起始角+累积扫过角）
```

手势定义（均相对画布坐标，单指针）：

1. **idle 按下**：圆心 = 落点，进入 `placing`，半径实时跟随指针（拖多远画多大）。
   抬手时 `r ≥ MIN_R(16px)` → `ready` 并记忆半径；`r < MIN_R`（视为点按）→ `ready` 且 `r =` 上次记忆半径（默认 80px）——「拿起预先张好的圆规直接放下」。
2. **ready 按下命中半径手柄**（距手柄 ≤ 14px 命中区）：进入 `resizing`，拖动实时改 `r`（clamp ≥ MIN_R）。手柄锚在参考圆上、角度取最近一次交互的落角（初始 0°，即正右方）。
3. **ready 按下其他位置**：进入待定画弧；位移超过 6px 才真正开始（区分「点按」）；画弧期间所有落点**夹紧在半径 r 的圆周上**（只取指针方位角），扫过角按最短角差方向累积（可来回改向）；`|sweep| ≥ 2π` 时自动闭合成整圆并立即提交。
4. **drawing 抬手**：`|sweep| ≥ 2°` → 采样为 Stroke 提交（persist 时同步落 store）；否则丢弃。
5. **ready 点按**（位移 ≤ 6px）：圆心搬到点按处，半径保持——换位置画同半径圆/弧（几何作图常用：多处画等半径弧找交点）。
6. **「整圆」按钮**（控制条）：以当前 `cx,cy,r` 直接提交整圆。
7. **「重置」按钮**：回 `idle`。

### 3.2 渲染（redraw 内，工具激活时叠加在笔迹之上）

| 元素 | 画法 |
|---|---|
| 参考圆 | 虚线 `setLineDash([4,6])`，颜色取 CSS 变量 `--text-tertiary`，globalAlpha 0.6 |
| 圆心 | 实心圆点 r=3（ink 色） |
| 半径手柄 | 实心圆点 r=4.5（ink 色），锚在参考圆上 |
| 半径线 | 圆心→手柄细线（同参考圆样式），提示半径方向 |
| 弧预览 | ink 色实线，与笔迹同款 `strokePath` 渲染（视觉上就是「画出来了」） |
| 半径数值 | `placing`/`resizing` 过程中在手柄旁 `fillText`（px 取整），落定后消失（控制条常显读数） |

### 3.3 控制条（工具条下条件渲染的第二行）

- 状态提示文案：idle→「点按放置圆规，拖动调整半径」；ready→「拖动画弧，点按移动圆心」；
- 半径读数：`半径 {n}`（px 取整）；
- 「整圆」「重置」文字按钮（`text-xs`，样式与工具按钮同族）。仅 ready 态可用（idle 时置灰/隐藏）。

### 3.4 边界与共存

- **与橡皮**：弧/圆是普通 Stroke，整条可擦；擦除不影响圆规状态（可擦掉画歪的弧再补）。
- **与贴图/移动**：compass 激活时 canvas 接管指针（贴图不可拖，与 pen 一致）。
- **scroll-y 两指平移**：第二指落下进入平移时取消进行中的弧预览（不提交），ready 态保留。
- **切工具再切回**：状态保留、无参考线渲染期间的指针事件不进圆规分支。
- **persist=false**（训练页 DraftDrawer）：同样工作，仅不落 store。
- **切题/清空**：重置 idle。

## 4. 计划外新增（2026-09-09 用户反馈后即做）：选中/移动工具

圆规上线实测后用户提出：画的元素不能移动，需要一个「选中」工具，所有选中元素（线段、笔画、图片）都可移动。该功能不在原四阶段内，立即实现，并**取代原「移动」工具**（旧 move 仅图片可拖，被统一选中模型覆盖）。

### 4.1 交互规范

- **点选**：点击元素 → 选中（笔画优先命中——canvas 恒绘制在贴图之上，视觉上层先命中；均从末位向前找最上层）。
- **拖动移动**：按住选中元素拖动 → 平移整个选区；点中未选中元素时先替换选区再起移动（标准画板 UX）。
- **抓取区 = 选中元素的包围盒整体**（外扩 4px 容差）：不必精确压在笔画线上，圆/矩形等空心图形的内部空腔也能拖；悬停在抓取区内光标变抓手（grab）、拖动中 grabbing（直接改 DOM cursor，不走 React 重渲染）。
- **Shift 加选**：按住 Shift 点按元素 → 加入/移出选区（不起移动手势）。
- **框选**：空白处拖出矩形 → 包围盒与矩形相交的笔画 + 贴图全部选中（位移 ≤ 6px 视为点按 → 清空选区）。
- **Delete/Backspace**：删除选中元素（笔画整条、贴图整张；焦点在输入框时放行）。
- **贴图控制点**：选中图在贴图层渲染四角等比缩放控制点 + 删除钮（z-10 覆盖层压过 canvas 可点击）——保留旧移动工具的全部图片操作能力。
- 多选（笔画 + 贴图混合）可整体拖动；图片负方向夹 0（与旧拖动一致），笔画不平移夹限（与手写一致）。
- 打断收尾：两指平移 / pointercancel / 丢失捕获 → 移动按当前位置落盘、框选丢弃。
- 切题/清空/擦除：选区重置/裁剪；切工具保留选区（仅不渲染，与圆规同策略）。

### 4.2 实现要点

| 点 | 说明 |
|---|---|
| 选区数据 | 笔画按对象引用 `Set<Stroke>`（ref，选中框画在 canvas）、图片按 id `Set<string>`（另有 state 镜像驱动贴图层选中态） |
| 笔画平移 | 点列原位改写（浮点增量无取整误差），抬手 `setDraft` 落盘 |
| 图片平移 | 手势起点原位快照 + 总位移绝对定位（防逐帧增量取整漂移），`updateImages` 逐帧落盘 |
| 选中框 | canvas 虚线包围盒（brand 色）；框选拖拽时叠加半透明填充矩形 |
| DraftImageLayer 重构 | 选中态由父级 `selectedIds` 驱动；图片本体恒穿透（canvas 统一命中），控制点/删除钮装 z-10 覆盖层 |

## 5. 后续阶段概要（落地时各自展开详设）

- **Phase 2 直线（2026-09-09 已实现）**：按下定起点，拖动实时预览（与提交同款实线 WYSIWYG）；**Shift 吸附最近的 45° 倍数方向**（0/45/90/135°，长度取投影）；位移 ≤ 6px 视为点按不落笔；抬手提交为 2 点 Stroke（strokePath 对两点笔画退化为直线段，橡皮 distToSegmentSq 精确命中）。打断（两指平移/系统取消）取消预览不提交；切题重置。提交函数已通用化 `commitShapeStroke`（原 commitCompassStroke），后续阶段复用。
- **Phase 3 矩形/椭圆（2026-09-09 已实现）**：与直线共用 shape 手势骨架（按下定锚点 → 拖出对角 → Shift 约束 → 抬手采样提交，`shapeCommitPoints` 统一生成预览与提交点列，kind 记录起手工具防手势中切工具串形）。矩形 = 四边按 ~3px 弦长加密采样 + 末点闭合（只采四角会被 strokePath 中点贝塞尔平滑削掉拐角约 1/4 边长，实测修复）；椭圆 = 包围盒内参数化采样（弦长 ~1.5px 自适应 + 最少 64 点封底，末点闭合）；**Shift 修正为正方形/正圆**（取 |dx|/|dy| 较大者、保持拖拽方向象限）。预览为实线 WYSIWYG（与直线一致，修订原「虚线预览」方案）。工具条 flex-wrap 防窄抽屉溢出。
- **Phase 4 三角形（2026-09-09 已实现）**：状态机 idle → placing(1~2 顶点，橡皮筋虚线跟手) → adjust(3 顶点齐)。**按下即放顶点、按住拖动微调该顶点**（统一点按与拖放两种落点方式）；adjust 态拖任一顶点手柄（14px 命中区）调整形状，光标 grabbing。**Shift = 等边**：第三顶点放置时或 adjust 态拖顶点时按住，顶点取对面边的等边点（`nearestEquilateral` 靠指针一侧）。提交：控制条「确认」按钮或 Enter（焦点在可交互元素上放行不抢按键）→ `sampleClosedPolygon` 采样（与矩形共用加密防削角）；Escape/「重置」回 idle。两指平移/系统取消：顶点固定当前位置、状态不丢。
