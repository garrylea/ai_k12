# 页眉剥离（page chrome）+ 书尾识别：修复 extract 前置内容误判

日期：2026-09-01
状态：实施中

## 背景与现象

新书《（根据2022年版课程标准修订）义务教育教科书·数学九年级上册》（186 页 md）extract 阶段两类误判：

1. **正文页被误杀为 front matter**（静默丢 0 卡片）：
   - 17 页页首有 OCR 识别的运行页眉 `# 人民教育出版社`（028/029/050/056/064/067/092/097/119/124/132/156/159/177/179/182 等），被 `is_front_matter` 规则 1 的整页子串「出版社」命中（`extract_cli.py:35`）。
   - 4 页（123/133/154/181）页尾被 PDF 水印「仅供个人学习使用，未经授权不得另做他用」误杀（同一规则）。
2. **书尾非课程内容反而产出垃圾卡片**：
   - page_183（综合与实践「活动过程/活动评价」纯组织说明页）产出 7 张无意义卡片。
   - page_186（封底：ISBN/绿色印刷/拼音/书名）产出 2 张卡片，图片路径进了内容。

老版 2012 书尾部同类内容（161 词汇索引/162 后记/163 封底）恰好被现有规则碰对跳过，说明问题具有普遍性，规则需通用化。

## 用户决策（2026-09-01 brainstorming）

- 只跳过**纯组织说明页**（含真实数学任务的活动页如 182 保留）。
- 页眉剥离用**书级频率统计自动发现**（不写死「人民教育出版社」，适配其他出版社教材）。
- 书尾识别用**确定性关键词规则**（不加 LLM 分类层）。

## 设计

### 1. 新模块 `src/page_chrome.py`

- `compute_book_chrome(md_dir: Path) -> set[str]`：书级预扫描。读该书目录**全部** `page_*.md`（不能只扫 `--pages` 过滤后的子集，否则频率失真），每页取开头 2 + 结尾 2 个非空行，归一化（去 `#` 前缀/首尾空白）后统计出现页数；出现页数 ≥ `CHROME_MIN_PAGES`（3）**且**命中安全模式的行进入 chrome 集合。
- `strip_chrome(text: str, chrome: set[str]) -> str`：删除整行归一化后命中集合的行（任意位置）。
- 安全模式（`_is_chrome_pattern`）：含「出版社」；含「仅供个人学习」/「未经授权」/「版权所有」；纯 1-3 位数字（页码行）；ISBN 开头。

**安全网（新书 186 页实测数据）**：

| 行 | 页数 | 频率≥3 | 安全模式 | 结果 |
|---|---|---|---|---|
| 人民教育出版社（页首） | 17 | ✓ | ✓ | 剥 |
| 仅供个人学习使用，未经授权…（页尾） | 9 | ✓ | ✓ | 剥 |
| 练习（页首） | 8 | ✓ | ✗ | 保留 |
| 复习巩固 / 数学活动 / 小结 | 7/6/6 | ✓ | ✗ | 保留 |
| `$$`（跨页公式续行） | 14 | ✓ | ✗ | 保留 |
| 题干偶现「某出版社…」 | 1 | ✗ | — | 保留 |

频率管「是否反复出现的固定版式」，安全模式管「是否内容」——缺一不可。

### 2. `extract_cli.py` 主流程接线

- sources 过滤完成后按 `book_key`（`source.rel_path`）对每本书调 `compute_book_chrome(source.md_path.parent)`，缓存 `chrome_cache[book_key]`。
- 两处剥行：① `read_text()` 后、`is_front_matter` 前（判定基于干净文本）；② `scan_page()` 返回清洗文本后、`normalize_fullwidth_parens`/`split_page` 前（页眉不进卡片内容）。

### 3. `is_front_matter` 新增书尾规则

- ISBN 正则 / 「绿色印刷产品」→ 封底（186）。
- 标题行含 后记/附录/词汇索引 → 后记页（184、老书 161/162）。
- 「电话」+「(电子)邮箱」同现 → 联系方式块（184）。
- 组织说明页：{活动评价, 展示交流, 演示文稿, 组建合作团队, 研究小组, 研究报告, 方案构思, 自我反思} 命中 ≥3 → 183（实测命中 6），182（真实数学任务）命中 0 → 保留。
- 剥离后整页为空 → front matter（不限页码；修 185 这类页码 >10 的空版权尾页）。
- 现有规则 1-4 保留：剥行后仍含「出版社/版权所有」的只剩真版权页。
