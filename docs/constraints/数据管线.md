`convert_cli (MinerU) -> extract_cli (LLM) -> publish_cli (物化图片) -> db_loader_cli (MySQL)`；`refinery_cli.py` 串联 publish + db_loader，DB 由 `tools/db/install_mysql.sh` 初始化。题目内容回写工具 `answer_importer`（JSONL/Markdown → questions 的 answer/approach/explanation/type，`--export` 出模板 / `--apply` 幂等写入）。试卷答案补录是**两段式**（2026-10-28）：`answer_extract_cli`（按学科 case 从 md 提取 → 答案文档）→ `answer_importer --doc --paper-id`（回写，`answer_verified=1`）。

**答案提取的学科分派**：`src/subject_cases/` 一科一函数（语文独立实现，其余委托 generic）；**不要**把语文特例塞回通用 `question_splitter`，也**不要**在标点归一化里映射「、」（中文大题序号分隔符，归一后大题标题会混进上一题答案）；答案段题号必须**递增**，回退编号是评分细则，不能开新答案段（否则串到第 1 题）。

**改动前必读三条**（细节见 `docs/data-refinery-管线总结与后续.md` §3）：① LLM 配置用 `.env` 的 `LLM_BASE_URL`/`LLM_AUTH_TOKEN`（refinery 专属），**不要用 `ANTHROPIC_*`**（会被 shell 里 Claude Code 覆盖）；② `db_loader` 的 full-reload 有**业务数据守卫**（库里有 answers/error_books 等外键数据时默认报错退出），需显式 `--purge-business-data`（按 FK 安全序清空）或改用 `--load-cards` 增量；③ 重抽目标页用 `unmark_extracted` 而非 `--force`（`--force` 绕过 skip 分支会断 lesson_id 的跨页继承回填）。

其余 extract/publish/db_loader 细则（全角括号归一、页眉页脚剥离与书尾识别、二维码过滤、版次 edition 维度、页码锚定 lesson_anchor 等）属已稳定行为，见 `docs/ai-core-changelog.md`。
