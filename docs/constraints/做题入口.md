# 做题入口（freeform）— 硬约束

- **有文字就不识题**（2026-11-09）：录入框文字非空（纯文字或文字+配图）→ 按钮「开始作答」、直接进作答区，图片只当配图追加进题干；**只有图片**才走 MinerU + 切题，按钮「开始识题」。文字路径 `subjectId` 默认 1、`maxScore` 默认 10，在作答区顶部改。
- 识题主路径：MinerU `extract` → 本地 LLM 切题；本地失败才回退千问。MinerU 不可用 → 报错 + 手动输入，不做 VLM 兜底。
- 原题照片**不得**写入 `questions.content`，也**不得**交给判题/答疑模型；模型只吃识别后的题干 + 学生勾选的配图。
- 做题页【答疑】原样发送学生输入（空则「这题怎么做？」），不拼接「我的尝试是…」等模板；模型固定走 `freeform_tutor`（千问，流式 + 思考过程）。
- 做题页答疑用**教学法模板**：`prompts/freeform/tutor/{math,physics,chemistry}.md` + 共用 `prompts/system/freeform-core.md`（partial，三科只此一份核心）。改模板后必须 `npm run build` + 重启（PromptBuilder 模板缓存不失效）。
- 学科模块只按 `dto.subjectId → ai_dialogues.subject_id → math` 解析，**禁止**用 `ConversationService.loadContext.subject`（恒为 math，会给物理/化学学生发数学模块）。
- 学习档案（年级/教材/已学内容）**由服务端从 DB 推导**（`StudentScopeService.resolve(studentId, subjectId)`）：年级 `students.grade`；教材 `progress.textbook_version_id → textbook_versions.publisher`（缺省 `name`）；已学内容 `current_semester_id`（缺省按年级 `grade_N`）→ `units.sort_order ≤ 当前单元`，未设当前单元视为整册。前端**不得**再上报，`TutorDto` 也不收该字段；只进 system prompt，**绝不拼进 user message**。
- **做题错题重练**（2026-11-10）：错题本做题条目「重练」/「重练做题错题（N）」→ `/student/solve?redo=1`，复用做题页作答与 `freeform_judge`；队列存 `sessionStorage['training:freeform-redo']`（读后不删、刷新恢复、完成/退出清）。提交必须带 `questionId` 重判同一条；满分清零、不满分保留；**重练链路不发积分、不写 `practice_results`、不更新掌握度、不 bump level**。2026-11-14 起做题错题可按 `answerable` 直接进普通错题练习（那条链路发分、更新掌握度）。
- 重练配图：前端从题干提取 `/uploads/freeform/...` 作为 `figureUrls`；后端只对「`questionId` + source=freeform」跳过无权图，首次提交仍严格校验（400/1001）。
- 学生端**不做答疑前问卷、无「修改学习信息」入口**（2026-11-09 裁定，取代原 `useLearningProfileWizard` + localStorage 方案）。年级/年龄只因登录自动校准（9/1 升级、满 12 个月 +1、高三封顶）或家长在 `PATCH /api/parent/students/:id` 手工修正而变化。
- 做题页**不走**「详细解析」快路径（≥2 轮 + 关键词直出/查库）——`maybeStoredExplanation` 对 `aux_freeform` 直接返回 null。
- freeform 题：`source='freeform'`、`answer_verified=0`、`grade_band=NULL`；**判题后异步补 `question_knowledge_points`**（`FreeformTagCapability`，从学科知识点清单选 id，失败只 warn）；`options` 只存 label/text，写库与 `parseOptions` 读取都剥 `isCorrect`。
- 错题本：判题只在 `totalScore < maxScore` 时写；满分清零；**判题本身不发积分、不写 practice_results、不调 MasteryService**。**只答疑未提交的题也收**（2026-11-14）：首次真实答疑后异步结构化建题 + 进错题本；已有判题报告 / 已有错题行（含已清零）不重建；纯图片题建空答案题（`answerable=false`）。
- **答疑聊过即入库**（2026-11-14）：`scene='aux_freeform'` 会话里有真实回复（非题干锚 / 非 block）后，`FreeformChatIngestService.maybeIngest` 异步补题；判题已发生（`question_id` 非空或已有 `freeform_judge` 消息）则跳过。失败只 warn，绝不阻断答疑。
- **练习池解禁**（2026-11-14）：错题列表返回 `answerable`；有标准答案的 freeform 题可勾选进错题练习，挂 KP 后可进知识点专项；`judgeQuestion` 不再对 `source='freeform'` 返回 400。空答案仍走 `unanswered` 守卫。变式生成仅数学（物理/化学直接跳过）。家长端 `TRACK_SOURCES.training` 含 `freeform`（归 training 档）。
- 答疑会话 `scene='aux_freeform'`：**有聊天消息的会话**出现在【辅助答疑】历史（`scene=aux_qna,aux_freeform&hasChat=1`），可回放、可续聊；纯判题会话不显示；家长端回放仍排除。
- 提交后再次提交 = 重判同一题；首次提交后锁学科/满分。
- 题干只在选题页可编辑；作答页不提供编辑入口（2026-11-08 用户裁决）。
- 选题页题干是**就地编辑字段**：点选中卡的题干 → 原地变源码框（自动聚焦），点框外 / Esc → 回渲染；渲染态永远显示当前生效题干（≠ 识别原文）。不要退回「编辑题干 / 完成编辑」按钮或左右分栏（2026-11-09 用户裁决）。
- 草稿白板挂在作答卡**外面**的页面右栏（`AuxiliaryLayout` 的 `sidePanel` + `DraftPanel defaultWidthPct={45}`）：展开时整行铺满、大卡左移让位；抓手可拖 25%–55%（往左拖草稿变宽）、双击复位；收起时只在页面右上角留图标（`pageAction`），该图标不在作答卡内（2026-11-09 用户裁决）。
- 点【答疑】必须自动收起草稿并在 AI tab 隐藏草稿入口（对话要整宽）；笔迹靠白板 store 保留，回作答页点图标可继续。
- **【提交】不跳聊天**（2026-11-09）：结果直接渲染在作答 tab 的判题结果卡（结论 + 得分 + 我的答案 + 正确答案 + 完整报告 + 再答一次 / 答疑）；判题流仍写 `useChatStore`（供答疑带上下文），但不得自动 `setTab('ai')` / `setAiOpen(true)`。只有【答疑】才进 AI tab；已判题时的首问用「我还是没太懂」而不是重发学生答案。
- `judge` SSE 的 `result` 事件必须带 `correctAnswer`（模型 JSON 的 `question.answer`），否则结果卡无法直接显示正确答案。
- **判题中要让人看见在跑**（2026-11-09）：结果卡等待态实时显示思考过程 + 报告增量 + 已等待秒数，不能只放一个 spinner；「停止」置 `stopped`（与失败分开），停止后可「继续判题」；前端看门狗 `JUDGE_INACTIVITY_MS=120s` 无任何事件即 abort 并报 1009，防止无限转圈。
- **AI 输出必须是 Markdown + LaTeX + HTML + SVG**：聊天区与结果卡一律走 `preprocessMarkdown` + `markdownRehypePlugins`（含 rehype-raw / KaTeX / svg 属性名修正）；模型用 `\(...\)`、`\[...\]`、`svg` 围栏都必须被归一后渲染成公式/图形，不得原样显示源码。
- 草稿白板默认收起；展开即默认勾选「附上草稿」，收起即取消。
- 原图/配图/草稿上传走 `source=freeform`；配图落 `/uploads/freeform/<uuid>/`。
- 交付只给一条命令：`bash tools/freeform/setup.sh`。
