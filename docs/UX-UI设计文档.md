# K12 智学系统 UX/UI 设计文档

> 本文档依据 [K12智学系统-产品需求文档.md](./K12智学系统-产品需求文档.md) 与 [K12智学系统-AI辅导流程详细设计.md](./K12智学系统-AI辅导流程详细设计.md) 编写，作为 UI/UX 实现的页面结构、信息架构与交互流程基准。本文档不再定义 Token 数值，所有颜色、字号、间距、圆角、阴影以 `style.md` 为准。

## Context

K12 智学系统是一款面向小学到高中（6-18 岁）学生的 AI 智能学习产品，采用「主线课程闯关 + 辅线自由探索」双轨结构，以苏格拉底式 AI 辅导为核心。本设计文档需解决：

1. **护眼优先于美观**：学生长时间驻留页面必须落实 §7.11 日夜模式切换，且严格限定于 `student-theme-container` 沉浸层。
2. **双端差异**：学生端简洁橘红温暖风 + 家长端商务清爽，杜绝家长端被夜间模式渗透。
3. **首发数学学科**：MVP 阶段仅数学，但页面框架预留全学科扩展位。
4. **平板优先（iPad 横屏）**，PC 大屏与小尺寸自适应降级。

设计目标：让孩子愿意每天独立学习 30 分钟以上，让家长 1 分钟内掌握孩子的学情。

## 1. 设计总览与原则

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 护眼至上 | 学习沉浸层默认暖米色护眼，18:00-06:00 自动切浅灰底夜间模式；非沉浸层物理屏蔽夜间模式 |
| 自主可控 | 学生独立操作不依赖家长，所有功能可一指触达；家长低干预、按需查看 |
| 苏格拉底引导 | UI 设计鼓励"思考"而非"答案"——提示按钮、讨论按钮始终比"查看答案"更显眼 |
| 双轨清晰 | 主线/辅线必须在导航/错题本上明显区隔（通过文字标签"主线"/"辅线"、Tab 标题、路由物理隔离），避免学生混淆解锁逻辑；颜色统一为品牌橘红，不依赖颜色对比 |
| 即时反馈 | 答题、错题清零、闯关解锁均配以微动效与音效（可关闭），强化正反馈 |
| 严守边界 | UI 上 AI 对话气泡内嵌「学习相关性」提示带，闲聊话题以柔色阻断卡片呈现 |

### 1.2 学段视觉策略

| 学段 | 字号基准 |
|------|----------|
| 小学（1-6 年级） | 见 style.md §3 小学字号 |
| 初中（7-9 年级） | 见 style.md §3 初中字号 |
| 高中（10-12 年级） | 见 style.md §3 高中字号 |

配色、圆角、图标风格、动效强度全系统一，学段差异仅限字号。

### 1.3 双端视觉策略

- **学生端**：以星球节点表示章节，节点间用连线展示学习路径；登录、注册、学科选择、章节星链图、个人中心、设置、奖励册等"浅停留"页禁用夜间模式。整体为简洁橘红温暖风，不使用装饰性背景元素。
- **家长端**：商务白蓝调，强制日间，无星空元素，以数据卡片+曲线图为主。家长端从注册到管理台全程禁用 `student-theme-container`。布局、卡片、阴影、留白、简洁度与学生非学习页保持一致，仅配色不同。

### 1.4 三层视觉体系

| 层级 | 覆盖页面 | 容器约束 | 视觉特征 |
|------|----------|----------|----------|
| 非学习阶段学生页 | P1.1、P1.5、P1.6、P2.1、P5.x | 禁用 `.student-theme-container` | 背景 `#F5F0E8`，卡片式、分栏、强阴影，橘红品牌色 |
| 学习沉浸阶段 | P2.2-P2.8、P3.1 | 启用 `.student-theme-container` | 暖米白/浅灰底，护眼沉浸，依据 style.md §2 主题切换 |
| 家长端 | P6.x | 禁用 `.student-theme-container` | 商务白蓝，布局风格与学生非学习页一致 |

### 1.5 日夜模式作用域

日夜间切换**严格限定在学习沉浸阶段页面**；非学习页面与家长端全部页面强制日间，不接受系统时间或用户手动切换。

- **启用日夜切换**：课程详情（P2.2）、AI 讨论（P2.3）、课后作业（P2.4）、作业解析（P2.5）、单元检测（P2.6）、期中期末（P2.7）、成绩报告（P2.8）、辅轨答疑应用（P3.1）。这些页面必须包裹 `.student-theme-container`，按 18:00-06:00 自动切换，并允许在**学习沉浸页内**手动切换（如课程详情页右下角的「护眼」按钮）。
- **禁用夜间切换**：登录（P1.1）、注册流程、学科选择（P1.5）、入口选择页（P1.6）、章节星链图（P2.1）、个人中心（P5.1）、奖励册（P5.2）。这些非学习阶段学生页直接写死 `data-theme="student-day"`，不使用 `.student-theme-container`。
- **家长端全程禁用**：家长端所有页面（P1.2 子账号创建、P6.x 管理台）强制 `data-theme="parent"`，无日夜间切换。

- **数学公式**：KaTeX / MathJax 内嵌，采用 STIX Two Math 风格

字号表与学段差异见 `style.md §3`。

- **间距栅格**：见 `style.md §4`

- **阴影**：见 `style.md §4`，包含 card / elevated / glow 等层级

### 2.4 图标系统

- **风格**：线性 SVG（学生端与家长端均使用简洁线性图标）
- **尺寸**：16 / 20 / 24 / 32 / 48
- **学科图标**：登录后学科选择/入口选择页使用统一书形线性 SVG 图标，通过图标徽章底色区分可选/锁定状态；各学科的独立图形图标（数学=六边形+魔方、语文=毛笔卷轴等）仅在星图导航、教材卡片等学习场景使用
- **状态图标**：星球（关卡）、锁（未解锁）、勾选（已完成）、错题标记、奖励标记

## 3. 设计系统 - 组件层

### 3.1 基础组件

| 组件 | 关键规格 |
|------|----------|
| Button | Primary / Secondary / Ghost / Danger 四类；尺寸 sm/md/lg/xl；学习场景默认 lg 便于触控；颜色见 style.md §2 |
| Input | 圆角见 style.md §4；focus 态品牌色描边 + 柔光；placeholder 颜色按页面类型区分（非学习页 `Text-Placeholder #A3A3A3`，学习沉浸页 `Text-Tertiary`）；公式输入区右侧固定 ∑ 公式按钮 |
| Tag | 知识点标签/难度标签（易/中/难）/ 来源标签（作业/单元测/期中/期末/辅线） |
| Card | 三档高度：flat（背景区隔）/ raised（卡片）/ floating（弹层） |
| Modal | 居中弹层 + 暗化背景 |
| Toast | 顶部下滑，自动消失 3s；成功/错误/信息态颜色见 style.md §2 |
| Banner | 家长端异常预警最高优先级，顶部固定，含"立即查看"CTA |
| Progress | 线性进度（学期进度）/ 环形进度（错题清零）/ 星球轨道进度（闯关） |
| Skeleton | 卡片加载占位，避免白屏 |

### 3.2 业务组件

#### 3.2.1 教材卡片 `TextbookCard`
- 顶部：章节面包屑 + 卡片页码 X/N
- 中部：教材原文（正文 16px / 宽行距 1.6，卡片标题 18px）+ 必要插图
  - 单张卡片正文总字数（仅统计汉字、英文单词、数字，不含 Markdown 标记与 LaTeX 源码）**不得超过 700 字**（依据文字列 46rem × 无滚动 ~19 行的几何推导，详见 Card 内容生成与渲染设计文档 §2）。
  - 内容切片规则：优先按自然段落合并；加入下一段后若超过 700 字，则当前卡片在此结束；单段超过 700 字时按完整句子切割；语义上紧密相关的小标题与其后正文/例题应尽量放在同一张卡片。
  - 卡片内禁止出现纵向滚动条，超出的内容必须拆分到下一张卡片。
- 底部固定栏：左「上一页」/ 右「下一页」
- 右侧边底部：悬浮「讨论」入口（聊天气泡图标 + "讨论"文字）
- 划过文字可长按高亮，弹出"对这句讨论"快捷入口

#### 3.2.2 AI 对话气泡 `AIDialogue`
- 学生气泡：右侧
- AI 气泡：左侧
- 公式自动渲染 KaTeX
- 顶部贴一条"当前讨论范围：第 3 课「速度公式」第 2 页"灰色提示带（主线模式严格显示）
- 输入区：文字 / 公式编辑器 / 拍照 / 手写 四入口
- 连续 3 次失败后系统进入兜底状态，并弹出"看完整解析"卡片（§7.9 兜底）
- 闲聊触发时气泡变温和绿色，文案"我是你的学习助手，这个话题课后你可以和好朋友聊…"

#### 3.2.3 题目卡 `QuestionCard`
- 题干区（可含图、公式）
- 答题区（按题型自适应：单选/多选/填空/手写解答）
- 操作栏：「提示」（黄色，给思路）/「让 AI 讲一讲」（橙色，进入对话）/「提交」
- 提交后展开：判题结果 + 步骤批改 + 「加入错题本」自动提示

#### 3.2.4 错题卡 `ErrorBookCard`（**已废止，2026-09-20**）
- 该组件对应的 P4.1–P4.3 页面已废止（见 §5.4），组件本身已从前端删除。
- 原规格（供溯源）：错题来源 Tag（文字"主线"/"辅线"区分，颜色统一为品牌橘红）/ 错题级别徽章（L1-L5，越高色越深）/ 上次错误时间、知识点标签、难度 / 操作「重做」「看解析」「同类变式」
- 训练轨错题练习页的错题条目改用 `ErrorPracticePage` 自己的行内渲染（含同一套 L1–L5 级别配色）。

#### 3.2.5 闯关星球 `LevelPlanet`
- 已完成：绿色星球 + 错题清零勾选
- 当前：橙色脉动星球
- 未解锁：灰色暗淡星球 + 锁链
- 单元 BOSS（单元检测）：紫色巨型星球
- 期中/期末：特殊标记节点

#### 3.2.6 奖励卡 `RewardCard`
- 虚拟徽章与物质奖励统一使用同一组件框架
- 展示奖励名称、状态、获取条件或兑现进度
- 家长可在家长端点击"已兑现"切换状态

### 3.3 导航组件

#### 学生端导航（主轨/辅轨物理隔离）
- **入口选择页（P1.6）**：登录后落地，提供"主轨学习""辅轨答疑"两个入口；两轨互不可见，任一轨可"退出"返回此页
- **主轨导航**：顶部全局栏（左 Logo+学段年级、中央"星图导航"快捷）；底部学习浮动条（仅课程页）：当前进度环 + 退出按钮（回入口选择页）+ 护眼模式切换。**不含辅轨入口**

- **辅轨导航**：类 ChatGPT 单页答疑应用，无主轨入口。左侧会话列表；右侧聊天窗口；顶部"退出答疑"（回入口选择页）+ "下一个问题"按钮

#### 家长端导航
- **顶部**：Logo + 当前查看的孩子切换（多孩家庭）+ 异常预警 Banner 位
- **侧边**（2026-09-20 起以代码 `ParentNav.tsx` 为准，实际顺序）：消息 / 学生账号 / 仪表盘 / 学情报告 / 错题查看 / AI 对话回放 / **异常预警** / 目标设定 / 行为管控 / 奖励管理 / 账号设置
  - ⚠️ 原文清单**没有「异常预警」**，但不加则 Banner 点掉后页面不可达 → **有意新增**（偏差已记，见 §5.x P6.9 批注）；原文有的「订阅中心 / 订单管理 / 优惠券」**未实现**（P2 范围，连表都没有）

### 5.1 入口模块详细规范

#### P1.1 统一登录
- **功能**：家长与学生共用同一登录入口，系统根据用户名格式自动判断身份（手机号 → 家长；非手机号 → 学生）
- **输入**：用户名（手机号或学生用户名）+ 密码
- **输出**：
  - 识别为家长 → P6.1 家长仪表盘；首次注册 → P1.2 子账号创建引导
  - 识别为学生 → P1.5 学科选择（首发只展示数学）
- **布局**：居中卡片式表单，表单含用户名输入框、密码输入框、登录按钮、注册入口。具体按 `style.md §2.5` 登录页规范实现：全屏居中、背景 `Bg-Page #F5F0E8`、卡片上半部橘红品牌区 + 下半部纯白表单区、强阴影、简洁大气。
- **约束**：
  - 禁用夜间模式（依据 §7.11 物理屏蔽）
  - 注册仅限家长（手机号注册），学生账号由家长在管理台创建（依据 §7.8）
  - MVP 阶段家长与学生可共用同一设备，退出登录切换身份即可

### 5.2 主线学习模块详细规范

#### P2.2 课程详情（教材卡片阅读）学习沉浸层
- **功能**：以卡片形式分页展示教材原文，每页底部可发起 AI 讨论
- **输入**：左右滑动/键盘方向键切换卡片，点击右侧边底部「讨论」入口
- **输出**：完成所有卡片 → 解锁"开始课后作业"按钮 → P2.4
- **布局**：
  - 全屏沉浸模式（隐藏侧边栏）
  - 上方：章节面包屑 + 卡片页码 X/N + 退出按钮
  - 中部：教材卡片（大字号、宽行距、必要插图）
  - 底部固定栏：「上一页」/「下一页」
  - 右侧边底部：「讨论」入口（聊天气泡细线图标 + "讨论"文字，柔和灰色调，低视觉权重不干扰阅读）
  - 右下角悬浮：护眼模式切换 + 字号 A-/A+
- **约束**：
  - **必须启用 `student-theme-container`**，遵循 §7.11 日夜模式
  - 18:00-06:00 自动切夜间浅灰底
  - 行距加宽防疲劳
- **关键交互**：长按文字高亮→"对这句讨论"快捷入口

#### P2.3 AI 讨论模式 学习沉浸层
- **功能**：学生与 AI 苏格拉底式讨论当前卡片内容
- **输入**：文字 / 公式 / 拍照 / 手写
- **输出**：对话历史持续保留；学生表示"懂了"或主动关闭则结束讨论
- **布局**：
  - 半屏抽屉式从右侧滑出（不离开卡片，可对照阅读）
  - 抽屉顶部贴学习相关性提示带「当前讨论范围：第 3 课「速度公式」第 2 页」
  - 对话气泡区：AI 左侧 / 学生右侧
  - 底部输入区：四种输入方式切换
- **约束**：
  - 严格限定在当前卡片范围（依据 §6.1、§7.1）
  - AI 不直接给答案，遵循苏格拉底
  - 连续 3 次"不会/答错"触发兜底：系统进入兜底状态 + 完整解析卡片
  - 闲聊温和阻断 + 后台向家长端推送预警
- **关键交互**：可"换种说法"按钮快速请求重述；"我懂了"按钮结束讨论

#### P2.4 课后作业 学习沉浸层
- **功能**：完成当前课的 2-3 道真题（易/中/难）
- **输入**：题目作答（按题型自适应输入方式）
- **输出**：提交 → P2.5 判题；错题自动加入主线错题本
- **布局**：
  - 顶部：当前作业进度（1/3）+ 难度标签
  - 中部：题目展示区 + 作答区（公式编辑器/拍照/手写）
  - 底部：「提示」（黄色，给思路）/「让 AI 讲一讲」（橙色，进入 P2.3 主线讨论，限定当前知识点，不跳辅轨）/「提交」
- **约束**：
  - 提示按钮永远比"看答案"更显眼（鼓励思考）
  - 不会时多次点提示，系统逐步给思路而非完整答案
- **关键交互**：拍照解题入口、手写公式识别区

#### P2.5 作业解析与判题
- **功能**：展示判题结果、AI 批改、错题标记
- **输入**：查看解析、加入错题本（默认自动加入）、继续下一题

  - 顶部状态条：对 / 错（暗红，非纯红，减轻焦虑）

  - 错题加入提示："已加入错题本，记得改正哦"
- **约束**：
  - 主观题 AI 按步骤给分（§7.5）
  - 错误反馈温和（暗红色 + 文案）

#### P2.6 单元检测
- **功能**：单元最后一课作业错题清零后触发，覆盖该单元全部知识点

- **输出**：自动批改 → 成绩报告 → 错题进入主线错题本
- **布局**：
  - 顶部倒计时条 + 进度（1/10 题）
  - 题目分屏：左侧题干，右侧作答区
  - 底部：「标记」/「上一题」/「下一题」/「交卷」
- **约束**：
  - 限时严格执行
  - 错题必须清零才能解锁下一单元（§7.6）
  - 此页可启用夜间模式（学习沉浸层）

### 5.8 训练轨：薄弱点图谱（数学，2026-09-23）

#### 页面 `/student/training/weak-points`
- **入口**：训练首页第 4 张卡（四卡：专项练习 / 真题考试 / 错题练习 / 薄弱点图谱）。
- **布局**：顶部 `PageHeader`（回训练首页、标题「薄弱点图谱 · 数学」）；下方推荐条；主体 `lg` 起两栏——左为**一级折叠树（默认全收起）**、右为详情栏（**窄屏降级为底部抽屉**，同一 DOM 节点切 class）；底部页脚给覆盖口径。
- **推荐条三态**：有候选 →「最该补：X」+ 掌握度/样本/可抽题数 + **[开始补这个]**（**只此一个动作**，勿再加第二个按钮）；无候选 → 引导文案 +「去专项练习」/「去考试」；**拉取失败 → 整条不渲染**（图谱仍可用，一栏坏掉不拖垮另一栏）。
- **两个动作（都在详情栏，推荐条不放）**：「开始补这个」按「≥3 的最小可用档」开练并跳作答页；「看这个知识点的错题」跳 `/student/training/errors?kpId=<id>`（该页据此预填筛选并**首屏即按它查询**）。推荐条只留「开始补这个」——两个并列按钮会让学生分不清「一键补漏」的主路径。
- **树与详情**：点一级展开/收起二级；点二级 chip 在详情栏出对错数、样本可信度、最近作答与两个动作。
- **一级行状态标签三态**：**未开始**（该一级下无任何 `ok` 子项）/ **N 个待补**（`ok` 子项里 `level <= 2` 的有 N 个）/ **已掌握**（有 `ok` 子项但一个都不弱）。**第三态必须有**——少了它，全是 `level > 2` 的一级行会渲染成「0 个待补」这种无意义噪音（2026-09-23 真机冒烟发现）。

#### 约束
- **热力梯度**（`weak-point-heat.ts` 唯一实现）：色相固定 brand 橘红 `#ff6b35` 只调不透明度，**不得引入第二套配色**。
- **`WEAK_LEVEL_MAX = 2`（`level <= 2` ⟺ 掌握度 < 60%）是两个用途共用的口径**：① 一级行的「N 个待补」；② **推荐的第 4 道闸门**（已掌握的不算「该补」，见 API 文档 §4.5 / spec §5.4）。后端在 `knowledge-graph.dto.ts`、前端在 `weak-point-heat.ts` 各有一份**镜像常量**，**改一处必须同步另一处**——不一致就会出现「一级行说 0 个待补、推荐条却推它」的自相矛盾。
- **`masteryScore: null` = 从未作答**，**不是 0**（0 是「很弱」，语义相反）——渲染为「未开始」灰显，**绝不显示 0%**。
- **`confidence` 三态**由后端算好下发（`none`/`insufficient`/`ok`），前端**不重算阈值**；`insufficient` 额外用虚线边与「有结论但浅」区分。
- **页脚必须给覆盖口径**（`covered/total` + 未标注错题数）：数学约 457 道 active 题里只有约 45% 带 KP 标注，不说明会让学生误读成「只有这些问题」。
- **无 emoji**；图标用线性 SVG。

### 5.9 PC App 学习管控页规格（2026-09-23）

设计见 `docs/superpowers/specs/2026-09-23-pc-app-study-lockdown-design.md`。**三处界面**：

1. **学生端锁定中的剩余时间 pill**（`apps/web/src/kiosk/LockedPill.tsx`）
   - 位置：`fixed` + **顶部居中**（`left-1/2 top-3 -translate-x-1/2`）；**不要贴右上**——沉浸页顶栏右上角已有退出按钮，会撞在一起。
   - 样式：药丸形，底色/描边/文字全用 `--brand-*` 令牌（`--brand-100/500/600`），**不引入第二套配色**。
   - 文案：`剩余 N 分钟 · 本次学习时长未满，需家长解除后才能退出`；不足 1 分钟显示「剩余不足 1 分钟」（**不显示 0 或负数**）。
   - **界面优先于文字提示**：家长设了多久要能被**看到**，而不是只在学生点登出被拒时才解释。
2. **家长端 `/parent/controls` 第三块「单次学习锁定」**
   - 锁定时长输入（`1..480`，**留空 = 不设锁**）+「当前：N 分钟 / 未设锁」状态 + 「解除锁定」按钮。
   - 「解除锁定」在**查到没有进行中的会话**时禁用并给出原因；查询失败时**保持可点**（真正的闸门在服务端）。
   - 保存复用页面既有的「保存」按钮 —— **不给本块单独加**，否则两个「保存」让家长猜哪个生效。
3. **家长端仪表盘「学习时段」卡**
   - **列表而非聚合**：逐条「几点进去 → 几点出来」，最多近 7 天 10 条。
   - 三态：进行中（在线 / 已断开）、已退出；空态文案「近 7 天还没有学习记录」。
   - 与同页「学习时长」聚合卡**并列不替代**（数据源一个登录粒度、一个学习页粒度）。

> **PC App 布局裁决（2026-09-23）**：PC App **与 Web 使用同一套布局**，**不做三栏**。
> 原 §7.2 / style.md 的「PC App 三栏」承诺**已推翻（不做三栏）**。

## 6. 交互规范

### 6.1 关键交互流程

#### 6.1.1 主线一课闭环
```
进入课程 → 阅读卡片(N张) → [可选] 讨论 → 完成课后作业(2-3题)
  → 判题 → 错题入主线本 → 清零错题 → 发放课级奖励
  → 进入下一课 或 单元检测 或 期中/期末
```

#### 6.1.2 错题清零循环
```
打开错题本 → 选择待清零错题 → 重做
  → 做对 → 从清零列表移除
  → 做错 → 级别+1 → AI重讲知识点 → 动态生成变式题 → 继续做
```

#### 6.1.3 AI 兜底机制（§7.9）
```
学生答错/不会 → AI 苏格拉底引导
  → 累计 3 次失败 → 触发兜底
  → 中止提问，系统进入兜底状态
  → 输出完整解析步骤 + 答案
  → 配以知识点总结卡片
```

#### 6.1.4 闲聊温和阻断（§7.9）
```
学生输入非学习内容 → AI 检测
  → 系统以温和话术回应（亲切克制）
  → 后台向家长端推送"闲聊/注意力偏离预警"
  → 引导学生回到当前学习主题
```

### 6.2 动效规范

- **学习沉浸层**：使用柔和缓动 `ease-out-cubic`，时长 200-300ms
- **闯关庆祝层**：弹簧动效 `spring(0.6, 0.3)`，奖励物品展示动画
- **错题反馈**：暗红色状态 + 卡片轻微抖动（150ms）
- **夜间模式切换**：背景色 800ms 平滑过渡，避免突变刺眼
- **可访问性**：「减少动画」选项关闭所有非必要动效

### 6.3 反馈规范

- 答对：绿色对勾 + 轻快音效（可关闭）
- 答错：暗红叉（非纯红）+ 柔和提示音
- 闯关成功：满屏粒子 + 奖励展示
- 错题清零：环形进度满 + 渐变绿光 + "本课所有错题已清零！"

### 8.1 护眼措施（§7.11 落实）

| 措施 | 实现 |

### 8.3 心理健康保护

- 错误反馈温和、不焦虑化（暗红色 + 温和文案，避免红叉爆炸式反馈）

- 闲聊温和阻断，不严厉封禁
- 家长端异常预警，及时介入孩子情绪问题

## 10. 验证方式

设计交付后通过以下方式验证：

1. **PRD 对照走查**：按 §9.3 清单逐项核对，确保无违背 PRD 规则的设计。
2. **真实用户测试**：
   - 招募 3 名小学生、3 名初中生、3 名高中生，让其独立完成"从登录→完成一课→错题清零→解锁下一课"全流程，观察是否需要家长干预。
   - 招募 6 名家长，测试是否能在 1 分钟内掌握孩子学情、查看 AI 对话、处理异常预警。
3. **护眼模式实测**：在 18:00 后真机检验自动切夜间，确认沉浸层切换、非沉浸层屏蔽。
4. **设备覆盖**：iPad 横屏（首发主力）+ PC App + iPad 竖屏，验证响应式无错位。
5. **可访问性扫描**：使用 axe / Lighthouse 进行可访问性自动化检查，确保对比度、ARIA 标签达标。
6. **设计评审会**：UI/UX + 产品 + 教研 + 心理顾问 四方评审，确认无对学生造成焦虑的元素。
