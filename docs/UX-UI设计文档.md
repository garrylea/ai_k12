# K12 智学系统 UX/UI 设计文档

> 本文档依据 [K12智学系统-产品需求文档.md](./K12智学系统-产品需求文档.md) 与 [K12智学系统-AI辅导流程详细设计.md](./K12智学系统-AI辅导流程详细设计.md) 编写，作为 UI/UX 实现的页面结构、信息架构与交互流程基准。本文档不再定义 Token 数值，所有颜色、字号、间距、圆角、阴影以 `style.md` 为准。

## Context

K12 智学系统是一款面向小学到高中（6-18 岁）学生的 AI 智能学习产品，采用「主线课程闯关 + 辅线自由探索」双轨结构，以苏格拉底式 AI 辅导为核心。本设计文档需解决：

1. **护眼优先于美观**：学生长时间驻留页面必须落实 §7.11 日夜模式切换，且严格限定于 `student-theme-container` 沉浸层。
2. **双端差异**：学生端简洁橘红温暖风 + 家长端商务清爽，杜绝家长端被夜间模式渗透。
3. **首发数学学科**：MVP 阶段仅数学，但页面框架预留全学科扩展位。
4. **平板优先（iPad 横屏）**，PC 大屏与小尺寸自适应降级。

设计目标：让孩子愿意每天独立学习 30 分钟以上，让家长 1 分钟内掌握孩子的学情。

## 1. 设计总览与原则

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| 护眼至上 | 学习沉浸层默认暖米色护眼，18:00-06:00 自动切深邃暗茶金；非沉浸层物理屏蔽夜间模式 |
| 自主可控 | 学生独立操作不依赖家长，所有功能可一指触达；家长低干预、按需查看 |
| 苏格拉底引导 | UI 设计鼓励"思考"而非"答案"——提示按钮、讨论按钮始终比"查看答案"更显眼 |
| 双轨清晰 | 主线/辅线必须在视觉/导航/错题本上明显区隔，避免学生混淆解锁逻辑 |
| 即时反馈 | 答题、错题清零、闯关解锁均配以微动效与音效（可关闭），强化正反馈 |
| 严守边界 | UI 上 AI 对话气泡内嵌「学习相关性」提示带，闲聊话题以柔色阻断卡片呈现 |

### 1.2 学段视觉策略

| 学段 | 字号基准 |
|------|----------|
| 小学（1-6 年级） | 见 style.md §3 小学字号 |
| 初中（7-9 年级） | 见 style.md §3 初中字号 |
| 高中（10-12 年级） | 见 style.md §3 高中字号 |

配色、圆角、图标风格、动效强度全系统一，学段差异仅限字号。

### 1.3 双端视觉策略

- **学生端**：以星球节点表示章节，节点间用连线展示学习路径；登录、注册、学科选择、章节星链图、个人中心、设置、奖励册等"浅停留"页禁用夜间模式。整体为简洁橘红温暖风，不使用装饰性背景元素。
- **家长端**：商务白蓝调，强制日间，无星空元素，以数据卡片+曲线图为主。家长端从注册到管理台全程禁用 `student-theme-container`。布局、卡片、阴影、留白、简洁度与学生非学习页保持一致，仅配色不同。

### 1.4 三层视觉体系

| 层级 | 覆盖页面 | 容器约束 | 视觉特征 |
|------|----------|----------|----------|
| 非学习阶段学生页 | P1.1、P1.5、P1.6、P2.1、P5.x | 禁用 `.student-theme-container` | 背景 `#F5F0E8`，卡片式、分栏、强阴影，橘红品牌色 |
| 学习沉浸阶段 | P2.2-P2.8、P3.1、P4.x | 启用 `.student-theme-container` | 暖米白/暗茶金，护眼沉浸，依据 style.md §2 主题切换 |
| 家长端 | P6.x | 禁用 `.student-theme-container` | 商务白蓝，布局风格与学生非学习页一致 |

### 1.5 日夜模式作用域

日夜间切换**严格限定在学习沉浸阶段页面**；非学习页面与家长端全部页面强制日间，不接受系统时间或用户手动切换。

- **启用日夜切换**：课程详情（P2.2）、AI 讨论（P2.3）、课后作业（P2.4）、作业解析（P2.5）、单元检测（P2.6）、期中期末（P2.7）、成绩报告（P2.8）、辅轨答疑应用（P3.1）、错题本（P4.x）。这些页面必须包裹 `.student-theme-container`，按 18:00-06:00 自动切换，并允许在学习设置中手动切换。
- **禁用夜间切换**：登录（P1.1）、注册流程、学科选择（P1.5）、入口选择页（P1.6）、章节星链图（P2.1）、个人中心（P5.1）、奖励册（P5.2）、设置（P5.3）。这些非学习阶段学生页直接写死 `data-theme="student-day"`，不使用 `.student-theme-container`。
- **家长端全程禁用**：家长端所有页面（P1.2 子账号创建、P6.x 管理台）强制 `data-theme="parent"`，无日夜间切换。

## 2. 设计系统 - 基础层

> 本文档不再定义 Token 数值。所有颜色、字号、间距、圆角、阴影以 `style.md` 为准。本文档仅描述页面结构、内容、状态与交互流程。

### 2.1 颜色体系

#### 2.1.1 学生端 - 日间模式（默认护眼）

所有颜色 Token 见 `style.md §2.1 学生端日间模式`。

#### 2.1.2 学生端 - 夜间模式（暗茶金，18:00-06:00 自动）

所有颜色 Token 见 `style.md §2.2 学生端夜间模式`。

#### 2.1.3 家长端（强制日间，商务白蓝）

所有颜色 Token 见 `style.md §2.3 家长端配色`。

### 2.2 字体与字号

- **中文字族**：Inter（拉丁）/ system-ui > 苹方 / PingFang SC > 思源黑体 / Source Han Sans SC > 系统默认
- **数学公式**：KaTeX / MathJax 内嵌，采用 STIX Two Math 风格
- **代码/数字**：JetBrains Mono（成绩数字、倒计时使用等宽体保证对齐）

字号表与学段差异见 `style.md §3`。

教材卡片正文行距统一加宽，避免长时间阅读疲劳，具体数值见 `style.md §3`。

### 2.3 间距/圆角/阴影

- **间距栅格**：见 `style.md §4`
- **圆角**：见 `style.md §4`，统一变量 `--radius-card` / `--radius-button` / `--radius-pill`
- **阴影**：见 `style.md §4`，包含 card / elevated / glow 等层级

### 2.4 图标系统

- **风格**：线性 SVG（学生端与家长端均使用简洁线性图标）
- **尺寸**：16 / 20 / 24 / 32 / 48
- **学科图标**：登录后学科选择/入口选择页使用统一书形线性 SVG 图标，通过图标徽章底色区分可选/锁定状态；各学科的独立图形图标（数学=六边形+魔方、语文=毛笔卷轴等）仅在星图导航、教材卡片等学习场景使用
- **状态图标**：星球（关卡）、锁（未解锁）、勾选（已完成）、错题标记、奖励标记

## 3. 设计系统 - 组件层

### 3.1 基础组件

| 组件 | 关键规格 |
|------|----------|
| Button | Primary / Secondary / Ghost / Danger 四类；尺寸 sm/md/lg/xl；学习场景默认 lg 便于触控；颜色见 style.md §2 |
| Input | 圆角见 style.md §4；focus 态品牌色描边 + 柔光；placeholder 颜色按页面类型区分（非学习页 `Text-Placeholder #A3A3A3`，学习沉浸页 `Text-Tertiary`）；公式输入区右侧固定 ∑ 公式按钮 |
| Tag | 知识点标签/难度标签（易/中/难）/ 来源标签（作业/单元测/期中/期末/辅线） |
| Card | 三档高度：flat（背景区隔）/ raised（卡片）/ floating（弹层） |
| Modal | 居中弹层 + 暗化背景 |
| Toast | 顶部下滑，自动消失 3s；成功/错误/信息态颜色见 style.md §2 |
| Banner | 家长端异常预警最高优先级，顶部固定，含"立即查看"CTA |
| Progress | 线性进度（学期进度）/ 环形进度（错题清零）/ 星球轨道进度（闯关） |
| Skeleton | 卡片加载占位，避免白屏 |

### 3.2 业务组件

#### 3.2.1 教材卡片 `TextbookCard`
- 顶部：章节面包屑 + 卡片页码 X/N
- 中部：教材原文（正文 16px / 宽行距 1.6，卡片标题 18px）+ 必要插图
  - 单张卡片正文总字数（仅统计汉字、英文单词、数字，不含 Markdown 标记与 LaTeX 源码）**不得超过 700 字**（依据文字列 46rem × 无滚动 ~19 行的几何推导，详见 Card 内容生成与渲染设计文档 §2）。
  - 内容切片规则：优先按自然段落合并；加入下一段后若超过 700 字，则当前卡片在此结束；单段超过 700 字时按完整句子切割；语义上紧密相关的小标题与其后正文/例题应尽量放在同一张卡片。
  - 卡片内禁止出现纵向滚动条，超出的内容必须拆分到下一张卡片。
- 底部固定栏：左「上一页」/ 右「下一页」
- 右侧边底部：悬浮「讨论」入口（聊天气泡图标 + "讨论"文字）
- 划过文字可长按高亮，弹出"对这句讨论"快捷入口

#### 3.2.2 AI 对话气泡 `AIDialogue`
- 学生气泡：右侧
- AI 气泡：左侧
- 公式自动渲染 KaTeX
- 顶部贴一条"当前讨论范围：第 3 课「速度公式」第 2 页"灰色提示带（主线模式严格显示）
- 输入区：文字 / 公式编辑器 / 拍照 / 手写 四入口
- 连续 3 次失败后系统进入兜底状态，并弹出"看完整解析"卡片（§7.9 兜底）
- 闲聊触发时气泡变温和绿色，文案"我是你的学习助手，这个话题课后你可以和好朋友聊…"

#### 3.2.3 题目卡 `QuestionCard`
- 题干区（可含图、公式）
- 答题区（按题型自适应：单选/多选/填空/手写解答）
- 操作栏：「提示」（黄色，给思路）/「让 AI 讲一讲」（橙色，进入对话）/「提交」
- 提交后展开：判题结果 + 步骤批改 + 「加入错题本」自动提示

#### 3.2.4 错题卡 `ErrorBookCard`
- 错题来源 Tag（颜色区分主线/辅线）
- 错题级别徽章（L1-L5，越高色越深）
- 上次错误时间、知识点标签、难度
- 操作：「重做」/「看解析」/「同类变式」

#### 3.2.5 闯关星球 `LevelPlanet`
- 已完成：绿色星球 + 错题清零勾选
- 当前：橙色脉动星球
- 未解锁：灰色暗淡星球 + 锁链
- 单元 BOSS（单元检测）：紫色巨型星球
- 期中/期末：特殊标记节点

#### 3.2.6 奖励卡 `RewardCard`
- 虚拟徽章与物质奖励统一使用同一组件框架
- 展示奖励名称、状态、获取条件或兑现进度
- 家长可在家长端点击"已兑现"切换状态

### 3.3 导航组件

#### 学生端导航（主轨/辅轨物理隔离）
- **入口选择页（P1.6）**：登录后落地，提供"主轨学习""辅轨答疑"两个入口；两轨互不可见，任一轨可"退出"返回此页
- **主轨导航**：顶部全局栏（左 Logo+学段年级、中央"星图导航"快捷）；侧边二级导航（学习时折叠为收起态）：星图导航 / 主线错题本 / 奖励册 / 学情报告 / 个人中心；底部学习浮动条（仅课程页）：当前进度环 + 退出按钮（回入口选择页）+ 护眼模式切换。**不含辅轨入口**
- **辅轨导航**：类 ChatGPT 单页答疑应用，无主轨入口。左侧会话列表 + 辅线错题本入口；右侧聊天窗口；顶部"退出答疑"（回入口选择页）+ "下一个问题"按钮

#### 家长端导航
- **顶部**：Logo + 当前查看的孩子切换（多孩家庭）+ 异常预警 Banner 位
- **侧边**：仪表盘 / 学习报告 / 错题查看 / AI 对话回放 / 目标设置 / 行为管控 / 奖励管理 / 订阅中心 / 订单管理 / 优惠券 / 账号设置

### 5.1 入口模块详细规范

#### P1.1 统一登录
- **功能**：家长与学生共用同一登录入口，系统根据用户名格式自动判断身份（手机号 → 家长；非手机号 → 学生）
- **输入**：用户名（手机号或学生用户名）+ 密码
- **输出**：
  - 识别为家长 → P6.1 家长仪表盘；首次注册 → P1.2 子账号创建引导
  - 识别为学生 → P1.5 学科选择（首发只展示数学）
- **布局**：居中卡片式表单，表单含用户名输入框、密码输入框、登录按钮、注册入口。具体按 `style.md §2.5` 登录页规范实现：全屏居中、背景 `Bg-Page #F5F0E8`、卡片上半部橘红品牌区 + 下半部纯白表单区、强阴影、简洁大气。
- **约束**：
  - 禁用夜间模式（依据 §7.11 物理屏蔽）
  - 注册仅限家长（手机号注册），学生账号由家长在管理台创建（依据 §7.8）
  - MVP 阶段家长与学生可共用同一设备，退出登录切换身份即可
  - 正式版迭代时再做物理设备隔离（依据 §7.8 后续规划）
- **关键交互**：
  - 注册流程：点击"注册" → 手机号 + 密码 + 监护人协议勾选 → 注册成功进入 P1.2
  - 忘记密码：家长可自助通过手机验证码重置；学生需联系家长重置
  - 输入框背景 `Bg-Form #FAFAFA`，placeholder 颜色使用 `Text-Placeholder #A3A3A3`

#### P1.2 学生子账号创建
- **功能**：家长在控制台创建学生子账号
- **输入**：学生用户名（非手机号格式）、密码、头像、**年龄（必填）**、**年级（必填，单选下拉）**、教材版本、性别（可选）
- **输出**：账号创建成功，自动匹配课程体系

## 6. 交互规范

### 6.1 关键交互流程

#### 6.1.1 主线一课闭环
```
进入课程 → 阅读卡片(N张) → [可选] 讨论 → 完成课后作业(2-3题)
  → 判题 → 错题入主线本 → 清零错题 → 发放课级奖励
  → 进入下一课 或 单元检测 或 期中/期末
```

#### 6.1.2 错题清零循环
```
打开错题本 → 选择待清零错题 → 重做
  → 做对 → 从清零列表移除
  → 做错 → 级别+1 → AI重讲知识点 → 动态生成变式题 → 继续做
```

#### 6.1.3 AI 兜底机制（§7.9）
```
学生答错/不会 → AI 苏格拉底引导
  → 累计 3 次失败 → 触发兜底
  → 中止提问，系统进入兜底状态
  → 输出完整解析步骤 + 答案
  → 配以知识点总结卡片
```

#### 6.1.4 闲聊温和阻断（§7.9）
```
学生输入非学习内容 → AI 检测
  → 系统以温和话术回应（亲切克制）
  → 后台向家长端推送"闲聊/注意力偏离预警"
  → 引导学生回到当前学习主题
```

### 6.2 动效规范

- **学习沉浸层**：使用柔和缓动 `ease-out-cubic`，时长 200-300ms
- **闯关庆祝层**：弹簧动效 `spring(0.6, 0.3)`，奖励物品展示动画
- **错题反馈**：暗红色状态 + 卡片轻微抖动（150ms）
- **夜间模式切换**：背景色 800ms 平滑过渡，避免突变刺眼
- **可访问性**：「减少动画」选项关闭所有非必要动效

### 6.3 反馈规范

- 答对：绿色对勾 + 轻快音效（可关闭）
- 答错：暗红叉（非纯红）+ 柔和提示音
- 闯关成功：满屏粒子 + 奖励展示
- 错题清零：环形进度满 + 渐变绿光 + "本课所有错题已清零！"

### 7.2 适配策略

> **尺寸缩放（首发已实现）**：采用**流式等比缩放**——根字号 `html { font-size: clamp(14px, 0.234vw + 12px, 21px) }` 随视口宽度平滑变化，全站字号/圆角/间距以 rem 表达并随之等比伸缩（4K 整体放大、1080p 基准、iPad 收至下限），观感一致。断点仅用于**切换布局**（下列双栏/三栏/单栏），不再承担尺寸缩放。数值基准见 `style.md §3/§4`。

- **iPad 横屏**：双栏布局（卡片+讨论同屏）；底部固定操作栏
- **PC App**：扩展为三栏（导航+卡片+讨论），右侧增加学情侧边栏
- **iPad 竖屏**：单栏，讨论改为底部抽屉
- **手机**（后续）：全单栏，讨论占满屏，导航底部 Tab

### 7.3 触控与键盘

- 平板触控：所有按钮最小热区 44×44px
- PC 键盘：方向键切卡片，Enter 提交答案，Esc 关闭弹层
- 公式输入：PC 支持 LaTeX 直输，平板默认公式编辑器面板

### 8.1 护眼措施（§7.11 落实）

| 措施 | 实现 |
|------|------|
| 暖米色背景 | 学习层默认背景色见 style.md §2.1，杜绝纯白 |

| 屏幕亮度联动 | 检测环境光（如支持），夜间模式同步降低应用内亮度感知 |

### 8.2 可访问性

- 字号系统：A- / A / A+ 三档（额外向小学倾斜大字号）
- 高对比度模式：视障辅助选项
- 屏幕阅读器：ARIA 标签覆盖所有交互
- 减少动效：开关关闭非必要动画
- 公式可读化：KaTeX 渲染同时输出 alt 文本

### 8.3 心理健康保护

- 错误反馈温和、不焦虑化（暗红色 + 温和文案，避免红叉爆炸式反馈）
- 兜底机制（§7.9）防长期挫败
- 闲聊温和阻断，不严厉封禁
- 家长端异常预警，及时介入孩子情绪问题

## 10. 验证方式

设计交付后通过以下方式验证：

1. **PRD 对照走查**：按 §9.3 清单逐项核对，确保无违背 PRD 规则的设计。
2. **真实用户测试**：
   - 招募 3 名小学生、3 名初中生、3 名高中生，让其独立完成"从登录→完成一课→错题清零→解锁下一课"全流程，观察是否需要家长干预。
   - 招募 6 名家长，测试是否能在 1 分钟内掌握孩子学情、查看 AI 对话、处理异常预警。
3. **护眼模式实测**：在 18:00 后真机检验自动切夜间，确认沉浸层切换、非沉浸层屏蔽。
4. **设备覆盖**：iPad 横屏（首发主力）+ PC App + iPad 竖屏，验证响应式无错位。
5. **可访问性扫描**：使用 axe / Lighthouse 进行可访问性自动化检查，确保对比度、ARIA 标签达标。
6. **设计评审会**：UI/UX + 产品 + 教研 + 心理顾问 四方评审，确认无对学生造成焦虑的元素。
