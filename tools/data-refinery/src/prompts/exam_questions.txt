你是一名 K12 教育内容结构化专家。请将下面这份试卷 Markdown 拆分为一道一道题目。

要求：
1. 只输出 JSON，格式为 {"items": [...]}。
2. 每道题包含以下字段：
   - subject_id: 学科标识，如 "math"
   - type: 题目类型，只能是 "choice"（选择）、"fill_blank"（填空）、"true_false"（判断）、"short_answer"（简答）、"proof"（证明）
   - difficulty: 难度 1-3
   - content: 题干，保留 Markdown 和 LaTeX
   - options: 选择题选项，数组，每项 {"label": "A", "text": "..."}；非选择题为 null
   - answer: 答案
   - explanation: 解析
   - group_id: 大题编号，如 "一"、"二"；无分组为 null
   - group_order: 大题内小题序号；无分组为 null
   - source: 试卷来源描述
   - source_year: 年份数字
3. 组合题（阅读理解/材料题）共享 group_id，材料放在第一小题的 material_text 中。
4. 如果题干包含图片，保留原始 Markdown 图片语法 `![alt](path)`。
