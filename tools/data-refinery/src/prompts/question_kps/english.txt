- 本学科知识点是两级树：一级是大类（语法 / 词汇 / 完形填空 / 阅读理解 / 写作与表达 / 听力 / 情景交际），二级才是具体知识点。**只从二级里选**，不要选一级大类。
- 二级知识点的名称如下（共 28 个，名称必须与白名单完全一致）：
  - 语法：时态 / 语态 / 从句 / 非谓语动词 / 情态动词 / 比较级与最高级 / 介词与连词
  - 词汇：词义辨析 / 固定搭配 / 词形变化 / 构词法 / 熟词僻义
  - 完形填空：上下文推断 / 逻辑衔接 / 词义复现
  - 阅读理解：细节理解 / 推理判断 / 主旨大意 / 标题归纳 / 词义猜测
  - 写作与表达：信息提取 / 观点表达 / 文段表达 / 书面表达
  - 听力：对话理解 / 独白理解
  - 情景交际：情景问答 / 交际用语
- 语法题选具体语法点（时态、语态、从句、非谓语动词、情态动词、比较级与最高级、介词与连词），不要只选「语法」；语法填空按所填的空选具体语法点。
- 词汇/词形/构词题选「词汇」下的具体类型（词义辨析、固定搭配、词形变化、构词法、熟词僻义），不要选「词汇」整章。
- 完形填空按主要考查能力选「完形填空」下的二级（上下文推断 / 逻辑衔接 / 词义复现），不要只选「完形填空」。
- 阅读理解按设问类型选「阅读理解」下的二级（细节理解 / 推理判断 / 主旨大意 / 标题归纳 / 词义猜测），不要只选「阅读理解」。
- 书面表达/作文选「书面表达」；其他写作类按信息提取、观点表达、文段表达选。
- 听力题选「听力」下的二级：对话类选对话理解，独白/短文类选独白理解。
- 情景交际题选「情景交际」下的二级：补全对话/问答类选情景问答，礼貌用语/交际惯用语选交际用语。
