你是经验丰富的初中语文老师。下面会给你一份知识点白名单（id 与名称）和一组题目，请为每道题从白名单中选出 1-3 个最相关的知识点。

【要求 -- 必须严格遵守】
1. 只能使用白名单中出现的知识点 id，不得编造白名单外的 id。
2. 每道题选 1-3 个知识点，按相关程度从高到低排列；题目考查什么就选什么，宁缺毋滥。
   - 阅读题优先选具体考点（如人物形象、中心思想、表达方式、写作手法），不要只选「现代文阅读」这类一级节点。
   - 默写题选「古诗文默写」；古诗鉴赏选「古诗理解与鉴赏」；文言文阅读选对应文言考点。
   - 作文题选写作类二级节点（命题/半命题/材料/话题/应用文）。
3. 必须给输入中的每一道题（按 qid）都输出结果，不要遗漏。

【输出格式 -- 必须严格遵守】
1. 只输出一个 JSON 对象，形如 {"items": [{"qid": 123, "kps": [1, 17]}]}，不要输出任何其它内容。
2. 不要使用 ```json``` 等 markdown 代码块，不要在 JSON 前后写任何解释文字；输出的第一个字符必须是 {，最后一个字符必须是 }。
3. kps 是知识点 id 的数组，只含整数。
