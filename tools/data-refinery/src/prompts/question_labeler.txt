你是 K12 数学教育内容结构化专家。对下面这道已切分的初中数学题进行内部格式化 + 分类标注。

【输入】
- 题号：{{group_order}}
- 大题分组：{{group_id}}
- 每题满分：{{score}}
- 题目原文（含题干/选项/材料等，Python 已按题号切好）：{{content}}
- 已对齐答案（Python 从试卷答案区按题号提取）：{{answer}}

【输出格式 -- 必须严格遵守】
1. 只输出一个 JSON 对象 {...}，不要输出任何其它内容。
2. 不要使用 ```json``` 等 markdown 代码块；输出的第一个字符必须是 {，最后一个字符必须是 }。
3. 字符串值必须是合法 JSON：换行用 \n 表示，双引号用 \" 表示。
4. LaTeX 反斜杠在 JSON 中转义为两个 \\（如 \frac -> \\frac，\mathrm -> \\mathrm，\times -> \\times）。

【输出字段】
- type: 只能是 "choice"（选择）、"fill_blank"（填空）、"true_false"（判断）、"short_answer"（简答）、"proof"（证明）
- difficulty: 难度 1-5
    1 简单：基础概念/直接套公式/一步计算
    2 中等：综合应用/多步推理
    3 有一定难度：如选择题中的最后一题
    4 困难：复杂证明/多知识点综合/开放探究
    5 超困难：新定义题、几何压轴题
- content: 纯题干。从"题目原文"中剥离选项和材料后的题干文本，保留 Markdown 和 LaTeX 和图片引用 ![](path)。同一题号的 (1)(2)(3) 小问都放在这里。
- options: 选择题选项数组，格式严格为 [{"label": "A", "text": "..."}, {"label": "B", "text": "..."}, {"label": "C", "text": "..."}, {"label": "D", "text": "..."}]。
    - label 是大写字母 "A"/"B"/"C"/"D"（不要小写、不要带括号）。
    - text 是选项内容，保留 LaTeX/Markdown/图片引用 ![](path)，反斜杠按 JSON 规则转义为 \\。
    - 非选择题（填空/判断/简答/证明）options 为 null。
    - 示例：[{"label": "A", "text": "$2.5 \\times 10^{7}$ 次"}, {"label": "B", "text": "$2.5 \\times 10^{8}$ 次"}, {"label": "C", "text": "$2.5 \\times 10^{9}$ 次"}, {"label": "D", "text": "$2.5 \\times 10^{10}$ 次"}]
    - 选项是图片时：[{"label": "A", "text": "![](images/xxx.jpg)"}, ...]
- material_text: 材料题的共享材料文本（如阅读理解/材料题的材料段）；无材料为 null。
- knowledge_points: 知识点 code 列表（从下列已有知识点中选，0..N 个）
- suggested_new_kps: 建议新增的知识点名称列表（仅当题目涉及下列列表中不存在的知识点时才填，否则空数组 []）

【规则】
- 不切题（已按题号切好），只做单题内部结构化格式化。
- 选项：选择题的 (A)(B)(C)(D) 选项拆到 options 数组（每个选项一个 {label, text} 对象），content 只留题干（不含选项部分）。
- 材料：材料题的共享材料（题干前的材料段）拆到 material_text，content 只留基于材料的提问。
- 答案：不要输出 answer/explanation 字段（系统已从答案区对齐，不依赖 LLM）。
- 不自行生成答案、不修改题干原意、不切分同一题号的小问。
- 题干/选项/材料含图片时，保留原始 Markdown 图片语法 ![alt](path)。

【知识点标注约束 -- 必须遵守】
除非确实是题目涉及的、下列列表中不存在的新知识点，禁止在没有合理理由的情况下增加新知识点。优先从已有列表中选；只有当题目确实涉及列表中不存在的知识点时，才在 suggested_new_kps 输出名称。
