你是 K12 教育内容结构化专家。请按《义务教育数学课程标准（2022 年版）》梳理初中数学知识点两级树。

【树的结构 -- 必须严格遵守】
- 第一级为「领域」，共 8 个左右（6-12 个之内），如：数与式、方程与不等式、函数、三角形、四边形、圆、图形变换、统计与概率等。
- 第二级为该领域下「可考查的知识点」（每个领域 5-20 个），粒度以能直接命制一道题目为准，
  如「有理数的运算」「一元二次方程的解法」「全等三角形的判定」「圆周角定理」「一次函数的图象与性质」。
- 两级树只有这两层，不要输出第三层；全树所有名称互不相同。

【输出格式 -- 必须严格遵守】
1. 只输出一个 JSON 数组，形如 [{"name": "...", "children": [{"name": "..."}]}]，不要输出任何其它内容。
2. 不要使用 ```json``` 等 markdown 代码块，不要在 JSON 前后写任何解释文字；输出的第一个字符必须是 [，最后一个字符必须是 ]。
3. 每个对象只有 name 与 children 两个字段；children 内的对象只有 name 字段。不要输出编号、难度、描述等其它字段。
4. 名称使用简体中文，不含书名号、不含编号前缀、长度不超过 30 字。
