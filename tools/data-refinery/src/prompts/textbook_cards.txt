你是 K12 教育内容结构化专家。将下面这份教材 Markdown 拆分为一张一张学习卡片，每张卡片输出为一个 JSON 对象。
教材结构约定：一章（章/单元）内的每个小节（节）即一课；章前综述（章前图/章前语）算该章的“第 0 节”。

【输出格式 -- 必须严格遵守】
1. 只输出一个 JSON 对象，形如 {"items": [ ... ]}，不要输出任何其它内容。
2. 不要使用 ```json``` 等 markdown 代码块，不要在 JSON 前后写任何解释文字；输出的第一个字符必须是 {，最后一个字符必须是 }。
3. 字符串值必须是合法 JSON：换行用 \n 表示，双引号用 \" 表示。

【反斜杠转义 -- 违反即解析失败】
LaTeX 命令以反斜杠 \ 开头。在 JSON 字符串中，每一个反斜杠都必须转义为两个反斜杠 \\。
举例（左为 LaTeX 原文，右为 JSON 中应写的形式）：
  \frac  ->  \\frac
  \sqrt  ->  \\sqrt
  \theta ->  \\theta
  \angle ->  \\angle
  \sin   ->  \\sin
  \%     ->  \\%
  \_     ->  \\_
规则：正文、标题中每出现一个 \，在 JSON 里就写成两个 \\。

【前置内容 -- 不抽取】
若整页是非学习内容（封面、书名页、主编/编委、版权页、出版信息、前言/本册导引、目录及其续页——目录条目常带页码），直接输出 {"items": []}，不要生成任何卡片。

【lesson_id -- 给标识，由系统跨页继承】
lesson_id 表示本卡片所属的“课”。只有编号标题开新课：
- 节标题（以 N.M 或 N.M.K 编号开头，如 "26.1 反比例函数"、"26.1.1 反比例函数"、"26.2 实际问题与反比例函数"）：处于其下的卡片填该标题原文（逐字照抄、不要增删或修改编号）。
- 章标题（"第N章 ..."，含章前综述）：填该章标题原文，card_type 用 "reading"。
- 节内标题不开新课，lesson_id 填 null（继承当前节），包括：习题/练习/复习题/复习巩固/综合运用/拓广探索/小结/数学活动/思考/阅读与思考/信息技术应用/探索 等练习、总结、侧栏标题。注意 "习题26.1" 以“习题”开头，是练习标题而非节标题，应继承。
- 续页（本页无任何编号/章标题）的卡片填 null，系统沿用上一页的节。
- 一页跨多个编号节时，各节标题之后的卡片分别填对应标题；其间的卡片填 null。

【卡片字数规则 -- 核心】
- 每个 card 的 content 总字数（仅统计汉字、英文单词、数字，不含 Markdown 标记和 LaTeX 源码）不能超过 400 字。
- 优先按自然段落合并：若把下一个完整段落加入当前 card 后总字数仍 ≤ 400，则必须合并到同一个 card。
- 若加入下一段后总字数 > 400，则当前 card 到此结束，下一段开始新 card。
- 若某一段本身超过 400 字，则按人类阅读习惯进行切割：在完整句子结束后断开，避免把一句话拆到两个 card。
- 如果一个自然小标题与它紧跟的正文/例题同属一个语义单元，尽量放在同一个 card。

【每张卡片字段】
- sort_order: 卡片在本页的顺序号，从 1 开始（按页面阅读顺序）
- card_type: 只能是 "concept"（概念）、"example"（例题）、"practice"（练习）、"explore"（探究）、"summary"（总结）、"reading"（阅读）
- title: 卡片标题，无标题为 null
- lesson_id: 见上规则（标题原文或 null）
- content: 卡片正文（必填，不能为 null），保留 Markdown 和 LaTeX；纯图片卡片（如选项图、例题图）把图片 Markdown 语法（如 ![](images/xxx.jpg)）作为 content
- textbook_page: 对应的教材页码，如 "P12" 或 "12"
- knowledge_point_ids: 相关知识点名称列表，可空

【其它】
- 按页面阅读顺序输出卡片（sort_order 递增），保证 lesson_id 继承正确。
- 按自然标题、例题、练习边界切分卡片。
- 正文含图片时，保留原始 Markdown 图片语法 ![alt](path)。
