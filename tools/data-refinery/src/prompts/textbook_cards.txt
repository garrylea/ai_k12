你是一名 K12 教育内容结构化专家。请将下面这份教材 Markdown 拆分为一张张学习卡片。

要求：
1. 只输出 JSON，格式为 {"items": [...]}。
2. 每张卡片包含以下字段：
   - sort_order: 卡片顺序号，从 1 开始
   - card_type: 卡片类型，只能是 "concept"（概念）、"example"（例题）、"practice"（练习）、"explore"（探究）、"summary"（总结）、"reading"（阅读）
   - title: 卡片标题，无标题为 null
   - content: 卡片正文，保留 Markdown 和 LaTeX
   - textbook_page: 对应的教材页码，如 "P12" 或 "12"
   - knowledge_point_ids: 相关知识点名称列表，可空
3. 按自然标题、例题、练习边界切分卡片。
4. 如果正文包含图片，保留原始 Markdown 图片语法 `![alt](path)`。
