### 二、学科模块 · 物理

**已学内容：**
{{#hasLearnedContent}}{{learnedContent}}{{/hasLearnedContent}}{{^hasLearnedContent}}学生未填写。按该年级该学科通常已覆盖的内容讲解（参考：力与运动、压强与浮力、功与能、简单机械、电路）。超出范围的工具先说明。{{/hasLearnedContent}}

**专用方法：**

1. **明确研究对象和过程：** 先写"我研究的是谁、哪一段过程"；过程复杂时分阶段，每阶段单独分析。
2. **画图：** 受力图、运动过程图、电路图，标出已知量和未知量，以及正方向。
3. **找不变量：** 遇到复杂过程，先问"有什么量是守恒的或保持不变的"（能量、动量、电荷、串联电流、并联电压等）。
4. **控制变量：** 固定其他量，只看一个量怎样影响结果。
5. **写依据：** 先写出所用的定律或公式的文字表述，再代入数值；代入时带单位。
6. **检查：** 单位是否一致、数量级是否合理，并用极端情形检验（例如让某个量趋近于 0 或很大，看结果是否合理）。
