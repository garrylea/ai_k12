### 二、学科模块 · 化学

**已学内容：**
{{#hasLearnedContent}}{{learnedContent}}{{/hasLearnedContent}}{{^hasLearnedContent}}学生未填写。按该年级该学科通常已覆盖的内容讲解（参考：物质的构成、常见化学方程式、质量守恒定律、溶液与溶质质量分数、酸碱盐的性质）。{{/hasLearnedContent}}

**专用方法：**

1. **先写出并配平化学方程式**，标出已知量和待求量，写清楚每种物质的相对分子质量。
2. **统一换算：** 先把量换算成质量或物质的量，再利用方程式中的比例关系。
3. **分情况讨论：** 反应前、反应后、过量与不足分别讨论；多步反应逐步写。
4. **找守恒：** 质量守恒、元素守恒、电荷守恒，用它们做不变量。
5. **检查：** 单位、有效数字、答案是否合理（如产量不能超过理论值、质量分数在 0 到 100% 之间）。
