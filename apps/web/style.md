# K12 智学系统 - 视觉风格规范（style.md）

> 本文件是所有页面与组件实现的**唯一配色与风格基准**。任何页面在编写前必须先读这份文档，落地时严格采用其中的 Token、字号、间距、圆角、阴影与组件规范。
>
> 与 [UX-UI设计文档.md](./UX-UI设计文档.md) 配合使用。当本文档与设计文档冲突时，以本文档为准。

---

## 1. 设计原则

1. **专注学习**：去除一切装饰元素、吉祥物、emoji、插画。学习层只保留文字、卡片、星球节点与必要的功能图形。
2. **护眼优先**：暖色调背景，避免高对比刺激；夜间模式平滑切换。
3. **信息密度**：用排版、色彩、间距传递层级，而非装饰图形。
4. **统一一套**：不再为小学/初中/高中设计三套不同配色。学段差异仅通过字号微调体现（见 §3）。
5. **禁用规则**：
   - 严禁使用任何 emoji（包括但不限于 🚀📚🎯✨ 等）
   - 严禁使用吉祥物或拟人化形象
   - 严禁使用装饰性插画、彩虹、气球、星星等点缀
   - 图标仅限功能图标（导航、状态、操作），使用线性 SVG

### 2.4 三层视觉体系

所有页面按用户所处场景分为三类，每类有独立的背景、主题容器与风格目标。

**日夜间切换仅在学习沉浸阶段页面生效**。登录、注册、学科选择、章节星链图、个人中心、设置、奖励册等非学习阶段学生页，以及家长端全部页面，均强制日间模式，物理屏蔽夜间切换。

| 类型 | 典型页面 | 主题容器 | 背景 | 风格关键词 |
|------|----------|----------|------|------------|
| 非学习阶段学生页 | P1.1 登录、P1.5 学科选择、P2.1 章节星链图、P5.1 个人中心、P5.2 奖励册、P5.3 设置 | 无，强制 `student-day` | `Bg-Page #FAFAFA` | 卡片式、分栏、强阴影、简洁大气 |
| 学习沉浸阶段 | P2.2 课程详情、P2.3 AI 讨论、P2.4 课后作业、P2.5 判题、P2.6/P2.7 检测考试、P2.8 成绩报告、P3.x 辅线、P4.x 错题本 | 有，启用日夜切换 | `Bg-Base #FAF6EE` / `#1A1612` | 护眼、沉浸、低刺激、简洁大气 |
| 家长端 | P6.1–P6.10 全部页面 | 无，强制 `parent` | `Bg-Base #F5F7FA` | 蓝白商务、与学生非学习页布局风格一致 |

**非学习阶段学生页**禁用 `.student-theme-container`，直接写死 `data-theme="student-day"`，物理屏蔽夜间模式。此类页面以白色卡片为载体，橘红仅用于标题区、主按钮与当前状态，整体留白充足，不使用任何装饰元素。

**学习沉浸阶段**必须包裹 `.student-theme-container`，按 18:00-06:00 自动切换日夜间。背景使用暖米白/暗茶金，组件阴影柔和，避免高对比与强装饰，优先保证长时间阅读与思考的舒适性。

**家长端**全程强制 `data-theme="parent"`，禁用夜间。布局、卡片、阴影、留白与非学习学生页保持一致，仅将品牌色与功能色替换为商务白蓝。

### 2.5 登录页规范（P1.1）

登录页是「非学习阶段学生页」的基准范例，其他浅停留页应参照其简洁大气的处理方式。

#### 2.5.1 布局

- 全屏居中，背景使用 `Bg-Page #FAFAFA`。
- 卡片最大宽度约 448px（`max-w-md`），在 PC 上保持居中不拉伸。
- 卡片结构：上半部橘红品牌区 + 下半部纯白表单区，圆角 `--radius-card`（16px），`overflow-hidden`。
- 卡片阴影使用 `--shadow-card-strong`。

#### 2.5.2 品牌区

- 背景：`Brand-500 #ff6b35`。
- 顶部功能图标：线性 SVG，白色描边，置于白色 10% 透明底 + 白色 30% 透明边框的圆角容器内。
- 标题：白色，`28–32px Bold`（按学段字号微调）。
- 副文案：白色 80% 透明度，简洁一句话，无多余说明。

#### 2.5.3 表单区

- 背景：白色 `#FFFFFF`。
- 输入框：背景 `Bg-Form #FAFAFA`，圆角 `--radius-input`（8px）。
- Focus 态：`Brand-500` 30% 透明描边光环。
- 主按钮：`Brand-500` 背景，白色文字，悬停 `Brand-400`，按下 `Brand-600`。
- 错误提示：`Error #C44A3F` 文字，`Error` 10% 透明背景。
- 底部链接：`Text-Secondary`，悬停变 `Brand-500`。

#### 2.5.4 禁用项

- 不出现吉祥物、emoji、装饰性插画。
- 不出现「演示说明」「仅限家长」等冗余小字。
- 不使用 `.student-theme-container`，不启用夜间切换。

## 3. 字体与字号

中文字族：苹方 / PingFang SC > 思源黑体 > 系统默认
数学公式：KaTeX 内嵌，STIX Two Math 风格
数字/代码：JetBrains Mono（成绩、倒计时等宽对齐）

字号基准（学段差异仅体现在字号，配色与圆角全部统一）：

| 用途 | 小学 | 初中 | 高中 |
|------|------|------|------|
| H1 大标题 | 28px Bold | 26px Semibold | 24px Semibold |
| H2 章节标题 | 22px Semibold | 20px Semibold | 18px Semibold |
| 卡片标题 | 18px Semibold | 16px Semibold | 15px Semibold |
| 正文 | 17px Regular | 15px Regular | 14px Regular |
| 教材卡片正文 | 19px / 行距 1.8 | 17px / 行距 1.7 | 16px / 行距 1.6 |
| 辅助说明 | 13px | 12px | 12px |

教材卡片正文行距统一加宽至 1.6-1.8，避免长时间阅读疲劳。

## 4. 间距、圆角、阴影

### 4.1 间距栅格
4px 基准。常用：4 / 8 / 12 / 16 / 24 / 32 / 48

### 4.2 圆角（统一，不按学段切换）
```
--radius-card:     16px
--radius-button:   10px
--radius-pill:     9999px
--radius-input:    8px
```

### 4.3 阴影（柔和，避免硬阴影）
```
--shadow-card:          0 2px 8px rgba(42, 31, 24, 0.06)
--shadow-elevated:       0 8px 24px rgba(42, 31, 24, 0.10)
--shadow-card-strong:    0 28px 70px rgba(0, 0, 0, 0.08),
                         0 10px 30px rgba(0, 0, 0, 0.04),
                         0 2px 8px rgba(0, 0, 0, 0.02)    /* 非学习页主卡片 */
--shadow-glow-brand:     0 0 16px rgba(255, 107, 53, 0.25)  /* 当前节点高亮 */
--shadow-glow-success:   0 0 12px rgba(74, 155, 110, 0.30)   /* 已完成节点 */
夜间模式所有阴影 alpha 翻倍（黑底叠加需要更强投影感）
```

## 5. 图标系统

- **风格**：线性 SVG，1.5px 描边，圆头线帽
- **尺寸**：16 / 20 / 24 / 32
- **学科图标**：每学科独立设计（数学=六边形、语文=卷轴、英语=字母方块），首发只实现数学
- **状态图标**：星球节点（章节）、小圆点（小节）、轨道线（连接）、锁（锁定）
- **严禁**：emoji 充当图标；吉祥物形象；装饰性插画

## 6. 核心组件规范

| 组件 | 关键规格 |
|------|----------|
| Button | Primary（Brand-500 橘红）/ Secondary（描边）/ Ghost / Danger 四类；尺寸 sm/md/lg/xl |
| Input | 圆角 8px；focus 态橘红描边 + 柔光；公式输入区右侧固定 ∑ 按钮 |
| Tag | 知识点/难度（易=绿/中=橙/难=暗红）/来源（作业/单元测/期中/期末/辅线） |

| Modal | 居中弹层 + 暗化背景；无吉祥物 |
| Toast | 顶部下滑，3s 自动消失 |
| Banner | 家长端异常预警最高优先级，顶部固定红底白字 |
| Progress | 线性（学期进度）/ 环形（错题清零） |
| Skeleton | 卡片加载占位 |
| PlanetNode | 章节星球，支持 large/medium/small 三档大小，状态：completed/current/locked |
| SectionCard | 小节卡片，显示编号、标题、知识点数、状态、进度 |

## 7. 章节星链图设计（核心页面 P2.1）

### 7.1 布局
- 顶部：学期标题 + 进度条（已完成章节数 / 总章节数）
- 中部：横向滚动的星链图，一条曲线连接所有章节星球
- 底部：选中章节后展开的小节卡片网格

### 7.2 星球大小（按章节重要性）
- **大星球**（80px）：核心章节、重难点章节
- **中星球**（56px）：普通章节
- **小星球**（40px）：复习章节、过渡章节

### 7.3 星球状态
- **已完成**：填充 Success 绿色，内部勾选标记，外环柔光
- **当前**：填充 Brand 橘红色，脉动光晕动画，外环高亮
- **未解锁**：填充灰色，内部锁图标，不可点击

### 7.4 交互
- 点击章节星球 → 选中态（外圈环 + 阴影提升） → 下方展开该章所有小节
- 长按星球 → 显示预览浮层（章节目标、知识点数、错题数）
- 横向滑动浏览整学期星链

### 7.5 小节卡片
- 网格布局，每行 3-4 个
- 卡片内容：小节编号、标题、知识点数、状态点、进度环
- 状态：已完成（绿点）/ 进行中（橘红点）/ 锁定（灰点）
- 点击进入对应小节学习

## 10. 主题切换机制

主题通过 CSS Variables + `data-theme` 属性实现，并严格按「三层视觉体系」挂载：

- **学习沉浸阶段**：外层包裹 `.student-theme-container`，通过切换 `data-theme="student-day"` / `data-theme="student-night"` 实现 18:00-06:00 自动日夜间切换。
- **非学习阶段学生页**（登录、注册、学科选择、章节星链图、个人中心、设置、奖励册等）：直接写死 `data-theme="student-day"`，**不使用** `.student-theme-container`，物理屏蔽夜间模式。背景使用 `Bg-Page #FAFAFA`。
- **家长端**：直接写死 `data-theme="parent"`，强制日间，禁用 `.student-theme-container`。

任何非学习学生页与家长端都不应响应系统时间或用户手动切换到夜间模式。

输入框占位符颜色按页面类型区分：
- **非学习阶段学生页与家长端**：使用 `Text-Placeholder #A3A3A3`，中性冷灰，视觉上更清爽。
- **学习沉浸阶段**：使用 `Text-Tertiary`（日间 `#9C8D80` / 夜间 `#7D7158`），暖调灰，与护眼背景色温保持一致。

实现上，非学习页与家长端直接读取 `--text-placeholder: #A3A3A3`；学习沉浸层包裹 `.student-theme-container` 后，该变量被覆盖为 `var(--text-tertiary)`，从而自动适配日夜间。

## 12. 响应式适配

### 12.1 断点

| 断点 | 设备 | 优先级 |
|------|------|--------|
| ≥1280px | PC App | 首发优先 |
| ≥1024px 横屏 | iPad 横屏 | 首发主力 |
| 768px–1023px | iPad 竖屏 | 二级 |
| <768px | 手机 | 后续迭代 |

### 12.2 适配策略

- **PC App**：学习沉浸层可扩展为三栏（导航 + 卡片 + 讨论/侧边栏）；非学习页卡片保持居中最大宽度，避免过宽。
- **iPad 横屏**：学习沉浸层双栏布局（卡片 + 讨论同屏），底部固定操作栏；非学习页保持居中卡片。
- **iPad 竖屏**：学习沉浸层改为单栏，讨论区变为底部抽屉；非学习页保持居中卡片。
- **手机**（后续迭代）：全单栏，讨论占满屏，导航使用底部 Tab。

### 12.3 触控与键盘

- 平板触控：所有可点击元素最小热区 44×44px。
- PC 键盘：方向键切换卡片，Enter 提交答案，Esc 关闭弹层。
- 公式输入：PC 支持 LaTeX 直输，平板默认公式编辑器面板。

## 13. 可访问性

### 13.1 对比度

- 正文文字与背景对比度 ≥ 4.5:1。
- `Brand-500 #ff6b35` 上的白色文字需实测，若对比度不足，改用 `Brand-600 #e85a28` 或加粗放大文字。

### 13.2 动画与动效

- 提供「减少动画」开关，关闭后禁用非必要动效（如星球脉动、庆祝动效等）。
- 日夜间模式背景切换过渡时长 800ms，避免突变刺眼。
- 普通交互反馈时长 150–300ms，使用 `ease-out-cubic` 缓动。

### 13.3 屏幕阅读器

- 所有图标按钮需有 `aria-label`。
- 表单输入需关联可见 `label`。
- KaTeX 渲染的公式需同时提供文本化 `alt` 描述。

### 13.4 心理健康保护

- 错误反馈使用暗红色 + 温和文案，不使用红叉、爆炸式视觉或焦虑化措辞。
- 兜底机制在学生连续失败时提供完整解析与知识点总结，避免长期挫败。
- 闲聊温和阻断，不严厉封禁，同时向家长端推送预警。
